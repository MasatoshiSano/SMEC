# 問題集（過去問完全マスター方式）

市販教材「過去問完全マスター」（同友館）に倣い、**論点別 × 重要度順**で問題集を構成する。
科目別の章立てで進むのではなく、出題テーマ（論点）ごとに過去問を並べ替え、頻出度の高い論点から優先的に学習できるようにするのが狙い。

## 構成の考え方

1. **見出し（論点リスト）を先に確定する**：`01_1st_stage_syllabus.md` の公式シラバス（大項目・中項目）を土台に、実際に出題されている粒度まで論点を分解する。
2. **頻出ランクを付与する**：`past_exams/1st_stage/` の過去問（平成19年度〜令和8年度）を年度ごとに読み、各論点が何年度に出題されたかを集計してランクを決める。
   - **ランクA**：直近10年で3回以上出題された最重要論点
   - **ランクB**：直近10年で2回出題された重要論点
   - **ランクC**：直近10年で1回のみ出題された論点（余裕があれば学習）
3. **設問を論点ごとに紐付ける**：過去問本体（PDF）から該当設問の年度・問番号を紐付け、実際に解く際の参照先とする（PDF自体の転記・複製は行わず、年度・問番号の索引のみを持つ）。

## 進め方（フェーズ管理）

- **フェーズ1（現在）**：見出し（論点リスト）の作成のみ。頻出ランク・出題年度索引は空欄のテンプレートとして用意する。
- **フェーズ2（次段階）**：過去問PDFを実際に読み込み、論点ごとの出題年度を集計してランクを確定する。
- **フェーズ3**：頻出論点から順に、解答・解説を付けた演習形式に仕上げる。

## ディレクトリ構成

```
problem_sets/
  README.md            本ファイル
  1st_stage/            第1次試験 科目別・論点別見出し（7科目）
    A_economics.md
    B_finance_accounting.md
    C_business_administration.md
    D_operations_management.md
    E_business_law.md
    F_information_systems.md
    G_sme_management_policy.md
```

第2次試験（事例I〜IV）は形式が異なる（論述式・与件文型のため論点別ランク付けになじまない）ため、対策方針は `docs/08_2nd_stage_solving_framework.md` の事例別フレームワークを引き続き参照する。
