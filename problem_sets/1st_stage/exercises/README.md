# 演習フォーマット（フェーズ3試作版）

`problem_sets/1st_stage/<科目>.md` の頻出ランク（A/B/C）に基づき、実際の過去問設問と解答・解説を紐付けた演習集。現時点では**財務・会計（B）・企業経営理論（C）の2科目、各6問の試作版**。

## フォーマットの構成要素

各設問は以下の要素で構成する：

1. **見出し**：`論点コード：大項目（小項目）｜出題年度 第◯問` の形式。論点コードは `problem_sets/1st_stage/<科目>.md` のNo列と対応させ、演習と論点表を相互参照できるようにする。
2. **設問文・選択肢**：過去問PDFからそのまま転記（表記ゆれの正規化のみ行う）。
3. **`<details>` タグで折りたたんだ解答・解説**：Markdown/GitHubで正しく畳める記法。ネタバレを防ぎ、自習形式で使えるようにする。
   - **正解**を明示
   - 各選択肢（正解・誤答とも）について、なぜ正しい／誤りなのかを1〜3行で説明する。計算問題は計算過程を示す。
   - 末尾に **関連知識** として `docs/07_key_formulas_and_frameworks.md` 等への参照を付け、演習だけで完結させず知識のインプット元に戻れるようにする。

## 今後の展開方針

1. このフォーマットで問題ないか確認（ユーザーレビュー待ち）。
2. 問題なければ、B・Cの残りのAランク論点、および他5科目（A, D, E, F, G）に同じフォーマットで展開する。
3. 素材は `past_exams/1st_stage/1ji<年度>/` の過去問と `past_exams/1st_stage_answers/` の正答を使う。複数年度から出題することで同一論点の異なる出題パターンに触れられるようにする。
4. 将来的には論点コードごとに複数問（3〜5問程度）持たせ、1論点を1セッションで演習しきれるボリュームにする。

## 出典・利用上の注意

設問文は日本中小企業診断士協会連合会（JF-CMCA）が無償公開している過去問からの引用。個人の学習目的での利用を前提とし、再配布・商用利用はしないこと（`../../../docs/05_sources.md` 参照）。解答・解説は本リポジトリで独自に作成したものであり、公式の模範解答ではない（第1次試験は正解のみ公表、解説は非公表）。
