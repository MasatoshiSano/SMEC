# 第1次試験 正解の訂正情報（令和3〜7年度）

出典：JF-CMCA（旧・中小企業診断協会）公式発表PDF（`docs/official_guides/corrections/`）。過去問を自己採点する際、以下の設問は「出題当時に公表された正解」と「最終的に有効な扱い」が異なるため、単純に模範解答通りに採点すると誤差が出る。

## 傾向

- 令和4〜7年度の4年間すべてで**運営管理（オペレーション・マネジメント）**に正解訂正が発生しており、最も訂正が多い科目。
- **経営情報システム**も令和4・6・7年度で訂正が発生。技術トレンドの変化が速く出題内容の検証が難しい科目であることが背景と推測される。
- 過去問演習でこれらの設問に当たった場合、模範解答通りに不正解としてしまうと実態と異なるため、上表を参照して「全員正解」だった設問として扱うこと。

## 第2次試験の運営上のトラブル（参考）

- **令和6年度第2次試験**：10月27日実施の筆記試験第3時限（事例III）で、東京地区・武蔵大学会場の一部受験者に対し試験終了時刻を誤って告知する事案が発生。該当受験者には得点への加点措置が取られた（`docs/official_guides/corrections/r06_2ji_syuryouzikan_ayamari.pdf`）。試験運営自体に起因するものであり、学習内容とは無関係。
