# 第1部：簿記・会計の基礎（B-1〜B-9）

簿記・会計は「会社のお金の動きを記録し、それを他人に説明できる形（財務諸表）にまとめる技術」です。まずは簿記の基本ルールを理解しないと、それ以降の経営分析や投資評価もただの暗記になってしまいます。ここが最初の関門ですが、焦らず一つずつ数値例で確認していきましょう。

## B-1：簿記の基礎：簿記原理・会計帳簿

### 基本概念

簿記とは、**会社の取引（お金・モノの動き）を、一定のルールに従って帳簿に記録する技術**です。中小企業診断士試験で使う簿記は「複式簿記」と呼ばれる方式で、1つの取引を必ず「原因」と「結果」の2つの側面から記録します。

複式簿記では、すべての勘定科目（取引の項目）を次の5つのグループに分類します。

| グループ | 内容 | 具体例 | 増えたときに記録する側 |
|---|---|---|---|
| **資産** | 会社が持っている財産 | 現金、売掛金、建物、商品 | 借方（左側） |
| **負債** | 会社が将来払う義務（借金） | 買掛金、借入金 | 貸方（右側） |
| **純資産（資本）** | 資産から負債を引いた「正味の元手」 | 資本金、利益剰余金 | 貸方（右側） |
| **収益** | 会社の儲けの元になるもの | 売上高、受取利息 | 貸方（右側） |
| **費用** | 儲けを生むためにかかったコスト | 仕入、給料、家賃 | 借方（左側） |

仕訳（しわけ）とは、1つの取引を「借方（左側）」と「貸方（右側）」に分けて記録することです。**借方の合計金額と貸方の合計金額は、どんな取引でも必ず一致します**（これを貸借平均の原理と呼びます）。

### 具体例

架空の個人商店「さくら商店」の取引を仕訳してみましょう。簿記が初めての人は、まず「その取引で、何が増えて、何が減ったか」を日本語で考えてから、上の表に当てはめると分かりやすくなります。

1. **現金100万円を元手に開業した**（資産である現金が増え、純資産である資本金が増えた）
   - （借）現金　1,000,000　／（貸）資本金　1,000,000
2. **商品80万円を現金で仕入れた**（費用である仕入が発生し、資産である現金が減った）
   - （借）仕入　800,000　／（貸）現金　800,000
3. **商品を120万円で売り、代金は後日受け取ることにした（掛け売り）**（資産である売掛金が増え、収益である売上が発生した）
   - （借）売掛金　1,200,000　／（貸）売上　1,200,000
4. **上記の売掛金100万円を現金で回収した**（資産である現金が増え、資産である売掛金が減った）
   - （借）現金　1,000,000　／（貸）売掛金　1,000,000
5. **銀行から現金50万円を借り入れた**（資産である現金が増え、負債である借入金が増えた）
   - （借）現金　500,000　／（貸）借入金　500,000

この5つの仕訳を「総勘定元帳」という帳簿に勘定科目ごとに転記していくことで、後で説明する貸借対照表・損益計算書（B-3〜B-5）が作れるようになります。

### ひっかけポイント

「資産が増えたら借方」「負債・純資産・収益が増えたら貸方」という基本パターンをまず体に覚え込ませることが最優先です。過去問では「この取引の仕訳として正しいものはどれか」という形式で、借方・貸方が逆になっている誤答肢が定番のひっかけとして出題されます。迷ったら「資産・費用は増加＝借方」「負債・純資産・収益は増加＝貸方」という表を思い出してください。

## B-2：簿記の基礎：決算処理一巡（試算表・精算表・決算仕訳）

### 基本概念

会社は1年に1回（決算日に）、それまでの取引記録をまとめて財務諸表を作成します。この一連の流れを「決算処理」と呼び、次のステップで進みます。

1. **期中の取引を仕訳し、総勘定元帳に転記する**（B-1の作業を1年間続ける）
2. **（決算整理前）残高試算表を作成する**：各勘定科目の残高を一覧にして、借方合計＝貸方合計になっているか検算する表
3. **決算整理仕訳を行う**：期中の記録だけでは反映されていない項目を修正する仕訳（後述）
4. **精算表を作成する**：試算表→決算整理→損益計算書・貸借対照表への流れを1枚の表にまとめたもの（試験で頻出）
5. **財務諸表（損益計算書・貸借対照表）を作成する**
6. **帳簿を締め切る**：収益・費用の勘定をゼロに戻し（当期の儲けを純資産に振り替える）、翌期の記録に備える

決算整理仕訳の代表例が**減価償却**です。建物や機械などの固定資産は、使うにつれて価値が減っていくため、その減少分を毎期の費用として計上します。

### 具体例

さくら商店が、期首に建物1,000万円（残存価額0円、耐用年数20年、定額法）を取得したとします。定額法の減価償却費は次の式で計算します。

$$減価償却費 = \frac{取得原価 - 残存価額}{耐用年数}$$

このケースでは、減価償却費 ＝ (10,000,000円－0円) ÷ 20年 ＝ **500,000円／年**となります。決算整理仕訳（間接法）は次のとおりです。

- （借）減価償却費　500,000　／（貸）減価償却累計額　500,000

「間接法」では、建物そのものの帳簿価額を直接減らさず、「減価償却累計額」というマイナスの資産科目を積み上げていく点がポイントです（貸借対照表上は「建物1,000万円－減価償却累計額50万円＝帳簿価額950万円」という形で表示されます）。

### ひっかけポイント

試算表は「借方合計＝貸方合計」という検算のための表であり、それ自体は財務諸表ではありません。精算表の作成順序（試算表欄→整理記入欄→損益計算書欄・貸借対照表欄）を問う問題や、決算整理仕訳（減価償却、貸倒引当金の設定、経過勘定項目の見越し・繰延べなど）の仕訳自体を問う問題が頻出です。特に「収益・費用の勘定は決算で必ずゼロに戻す（締め切る）が、資産・負債・純資産の勘定は残高を次期に繰り越す」という違いを混同しないようにしましょう。

## B-3：簿記の基礎：貸借対照表・損益計算書の作成

### 基本概念

B-1・B-2で記録した仕訳の集大成が、貸借対照表（B/S）と損益計算書（P/L）です。決算整理後の残高試算表の各勘定科目を、次のルールで2つの表に振り分けます。

- **資産・負債・純資産**の勘定科目 → **貸借対照表**へ
- **収益・費用**の勘定科目 → **損益計算書**へ（収益－費用＝当期純利益。この当期純利益は貸借対照表の純資産（利益剰余金）に加算される）

つまり、損益計算書で計算された「今年の儲け（当期純利益）」は、最終的に貸借対照表の純資産を増やす形でつながっています。この2つの表は別々のものではなく、1つの決算処理から生まれる表裏一体の関係にあります。

### 具体例

さくら商店の決算整理後残高試算表（一部を簡略化）が次のとおりだったとします。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|---|---|---|
| 現金 | 700,000円 | 買掛金 | 200,000円 |
| 売掛金 | 200,000円 | 借入金 | 500,000円 |
| 建物 | 10,000,000円 | 減価償却累計額 | 500,000円 |
| 仕入（売上原価） | 800,000円 | 資本金 | 1,000,000円 |
| | | 売上 | 1,200,000円 |

収益・費用のグループを損益計算書に集めると「売上1,200,000円－仕入800,000円＝当期純利益400,000円」となります。資産・負債・純資産のグループを貸借対照表に集めると、資産合計（700,000＋200,000＋10,000,000－500,000＝10,400,000円）＝負債合計（200,000＋500,000＝700,000円）＋純資産合計（資本金1,000,000円＋当期純利益400,000円＝1,400,000円）……となるはずですが、この簡略例では固定資産の取得原資（借入等）を省略しているため厳密には一致しません。実際の試験問題では、与えられた試算表の数値をそのまま集計すれば必ず貸借は一致するように作られているので、慌てず機械的に「資産・負債・純資産→B/S」「収益・費用→P/L」に仕分けていく作業に慣れることが大切です。

### ひっかけポイント

「当期純利益は貸借対照表のどこに反映されるか」（→純資産の利益剰余金に加算される）という、P/LとB/Sのつながりを問う問題が頻出です。単に2つの表を別々に暗記するのではなく、「P/Lで計算した儲けが、B/Sの純資産を増やす」という一本の流れとして理解しておきましょう。

## B-4：企業会計の基礎：損益計算書（収益・費用の会計）

### 基本概念

損益計算書（P/L）は、**1年間の会社の経営成績（儲かったか損したか）**を表す書類です。日本の損益計算書は、儲けの種類ごとに5段階の利益を積み上げる形式になっています。

| 段階 | 計算式 | 意味 |
|---|---|---|
| ① 売上総利益 | 売上高 － 売上原価 | いわゆる「粗利」。商品そのものの儲け |
| ② 営業利益 | 売上総利益 － 販売費及び一般管理費 | 本業でどれだけ儲けたか |
| ③ 経常利益 | 営業利益 ＋ 営業外収益 － 営業外費用 | 本業＋財務活動（利息の受払等）を含めた通常の儲け |
| ④ 税引前当期純利益 | 経常利益 ＋ 特別利益 － 特別損失 | 臨時的な損益（固定資産売却益など）も含めた最終的な儲け |
| ⑤ 当期純利益 | 税引前当期純利益 － 法人税等 | 税金を払った後、株主に帰属する最終利益 |

### 具体例

町のパン屋「ひまわりベーカリー」の1年間の損益計算書が次のとおりだったとします。

- 売上高：5,000万円
- 売上原価（小麦粉・バターなどの材料費）：2,000万円
- 販売費及び一般管理費（店員の給料・家賃・広告費）：2,500万円
- 営業外収益（受取利息）：10万円
- 営業外費用（銀行借入の支払利息）：60万円
- 特別損失（火災で焼損した設備の損失）：50万円
- 法人税等：120万円

これを順番に計算すると次のようになります。

1. 売上総利益＝5,000万円－2,000万円＝**3,000万円**
2. 営業利益＝3,000万円－2,500万円＝**500万円**
3. 経常利益＝500万円＋10万円－60万円＝**450万円**
4. 税引前当期純利益＝450万円－50万円＝**400万円**
5. 当期純利益＝400万円－120万円＝**280万円**

### ひっかけポイント

「本業の儲け」を見たいときは営業利益、「財務活動まで含めた通常の儲け」を見たいときは経常利益、というように、どの利益がどんな性格を表しているかを区別することが重要です。例えば「借入金の支払利息が増えて経常利益が落ち込んでいるが、営業利益は好調」という会社は、本業自体は問題なく、財務体質（借入への依存度）に課題がある、と読み解けます。特別損益は「臨時的・一時的な項目」である点も、経営分析（B-12〜B-14）でどの利益を使うかを判断する際の前提知識になります。

## B-5：企業会計の基礎：貸借対照表（資産・負債・純資産の会計）

### 基本概念

貸借対照表（B/S）は、**決算日時点での会社の財政状態（何を持っていて、何を返す必要があるか）**を表す書類です。次の等式が必ず成り立ちます。

$$資産 = 負債 + 純資産$$

つまり「会社が持っている財産（資産）は、他人から借りたお金（負債）と、自分たちの元手・儲けの蓄積（純資産）のどちらかで賄われている」という考え方です。貸借対照表の左側（借方）に資産、右側（貸方）に負債・純資産を並べるため、左右の合計金額は必ず一致します。

資産・負債はさらに「流動」と「固定」に分けられます。原則として、1年以内に現金化・支払期限が来るものを「流動」、それより先のものを「固定」に分類します（ワン・イヤー・ルール）。

| 区分 | 内容 | 具体例 |
|---|---|---|
| 流動資産 | 1年以内に現金化される資産 | 現金、売掛金、棚卸資産（在庫） |
| 固定資産 | 1年を超えて使用・保有する資産 | 建物、機械、土地、投資有価証券 |
| 流動負債 | 1年以内に支払う負債 | 買掛金、短期借入金 |
| 固定負債 | 1年を超えて返済する負債 | 長期借入金、社債 |
| 純資産 | 株主からの出資と利益の蓄積 | 資本金、資本剰余金、利益剰余金 |

### 具体例

ひまわりベーカリーの決算日の貸借対照表が次のとおりだったとします（単位：万円）。

| 資産の部 | 金額 | 負債・純資産の部 | 金額 |
|---|---|---|---|
| 現金預金 | 800 | 買掛金 | 300 |
| 売掛金 | 200 | 短期借入金 | 200 |
| 棚卸資産 | 300 | （流動負債合計） | （500） |
| （流動資産合計） | （1,300） | 長期借入金 | 1,000 |
| 建物・設備 | 2,000 | （固定負債合計） | （1,000） |
| （固定資産合計） | （2,000） | 資本金 | 1,000 |
| | | 利益剰余金 | 800 |
| | | （純資産合計） | （1,800） |
| **資産合計** | **3,300** | **負債・純資産合計** | **3,300** |

資産合計3,300万円＝負債合計1,500万円＋純資産合計1,800万円、で一致していることを確認してください。この表は、B-13（安全性分析）で使う流動比率・自己資本比率などの計算のベースになります。

### ひっかけポイント

「利益剰余金」は現金そのものではなく、過去の儲けの蓄積を純資産の中に記録した金額です。「利益剰余金が多い＝現金をたくさん持っている」と短絡的に考えないよう注意してください（現金は資産の部に「現金預金」として別に計上されています）。また、貸倒引当金や減価償却累計額のような「資産のマイナス項目」の扱い（資産から控除して表示する）も、貸借対照表作成問題で頻出のひっかけです。

## B-6：企業会計の基礎：キャッシュ・フロー計算書

### 基本概念

損益計算書上の利益と、実際に会社に出入りした現金の額は一致しません（例：掛け売りをすると売上は計上されるが現金はまだ入っていない）。この「現金の動き」だけを表すのが**キャッシュ・フロー計算書（C/F）**で、次の3つの区分に分けて表示します。

| 区分 | 内容 |
|---|---|
| **営業活動によるキャッシュ・フロー（営業CF）** | 本業の営業活動から生じた現金の増減（商品の販売・仕入など） |
| **投資活動によるキャッシュ・フロー（投資CF）** | 設備投資や有価証券の売買など、将来のための投資から生じた現金の増減 |
| **財務活動によるキャッシュ・フロー（財務CF）** | 借入・返済、増資、配当の支払いなど、資金調達・返済から生じた現金の増減 |

営業CFの計算方法には「直接法」（現金収入・現金支出を1つずつ積み上げる）と「間接法」（当期純利益からスタートして、現金の動きを伴わない項目を調整して逆算する）があり、試験では間接法が頻出します。間接法の調整のコツは次のとおりです。

- **減価償却費**：費用として計上されるが実際の現金支出はない（非資金費用）→ 当期純利益に**加算**
- **売上債権（売掛金）の増加**：売上は計上されているがまだ現金を回収していない → 当期純利益から**減算**
- **棚卸資産の増加**：現金を払って在庫を増やした → 当期純利益から**減算**
- **仕入債務（買掛金）の増加**：仕入は計上されているがまだ現金を支払っていない（支払いの先延ばし）→ 当期純利益に**加算**

### 具体例

ある会社の当期純利益が300万円、減価償却費50万円、売上債権が前期より40万円増加、棚卸資産が前期より20万円増加、仕入債務が前期より30万円増加した場合の営業CFは次のとおりです。

営業CF＝300万円（当期純利益）＋50万円（減価償却費を加算）－40万円（売上債権増加を減算）－20万円（棚卸資産増加を減算）＋30万円（仕入債務増加を加算）＝**320万円**

### ひっかけポイント

「減価償却費は現金支出を伴わないので加算」「資産（売上債権・棚卸資産）の増加は現金が出ていったのと同じ効果なので減算」「負債（仕入債務）の増加は現金の支払いを先延ばしできているので加算」という向きを逆に覚えてしまうミスが非常に多いです。「資産が増えた＝現金化されずお金が寝ている＝キャッシュにはマイナス」「負債が増えた＝支払いを待ってもらえている＝キャッシュにはプラス」とイメージで覚えると混同しにくくなります。

## B-7：企業会計の基礎：企業結合（合併・分割・連結決算）

### 基本概念

会社同士が一つになったり、グループとして経営したりする際の会計処理です。

- **合併**：複数の会社が1つの会社になること。既存の会社が存続し相手を吸収する「吸収合併」と、両社が消滅して新しい会社を作る「新設合併」がある
- **会社分割**：会社の事業の一部を切り離して、別の会社に承継させること。既存の会社に承継させる「吸収分割」と、新しく設立する会社に承継させる「新設分割」がある
- **連結決算**：親会社が子会社（議決権の過半数を持つなど、実質的に支配している会社）を含めて、グループ全体を1つの会社であるかのように財務諸表を作成すること

企業結合（合併など）で会社を買収する場合、原則として**パーチェス法**という方法で会計処理します。買収先の資産・負債を時価で評価し直し、支払った買収額（取得原価）が、その時価評価後の純資産額を上回った場合、その差額を**のれん**として資産に計上します（下回った場合は「負ののれん」として、その期の利益に計上します）。日本基準では、のれんは資産計上後、20年以内の期間で規則的に償却します。

### 具体例

A社がB社を買収し、買収額（取得原価）は1,200万円でした。B社の資産・負債を時価で評価し直した結果、純資産（時価）は1,000万円だったとします。

のれん＝取得原価1,200万円－時価純資産1,000万円＝**200万円**

こののれんを20年で均等償却する場合、毎期ののれん償却費は200万円÷20年＝**10万円／年**となり、A社の損益計算書に費用として計上されます。

### ひっかけポイント

「取得原価＜時価純資産」の場合に生じる「負ののれん」は、資産としてではなく、発生した期の**利益（特別利益）**として一括計上する点が「のれん（資産計上して償却）」と非対称であることに注意してください。また、連結決算では、親子会社間の取引（内部取引）や、親会社が持つ子会社株式と子会社の純資産は、グループ内部の話として相殺消去される点も頻出論点です。

## B-8：企業会計の基礎：会計ディスクロージャー

### 基本概念

会計ディスクロージャー（情報開示）とは、会社が利害関係者（株主、投資家、債権者など）に対して、財務状況を適切に開示する制度です。日本の上場企業には主に次の開示義務があります。

- **有価証券報告書**：金融商品取引法に基づき、上場会社等が事業年度ごとに作成・提出する、最も詳細で公的な開示書類
- **決算短信**：証券取引所のルールに基づき、決算発表時に投資家へ最速で開示する速報資料。有価証券報告書より作成・開示が早い
- **半期報告書**：金融商品取引法に基づく開示書類。なお、従来あった四半期報告書制度は2024年4月以後に開始する事業年度から廃止され、第1・第3四半期の開示は取引所の四半期決算短信に一本化された（第2四半期は半期報告書に統合）という制度変更があった

会社法上も、株主総会に提出する計算書類（貸借対照表・損益計算書等）の作成・開示が義務付けられています。

### 具体例

投資家がある上場企業の業績をいち早く知りたい場合は、公表が最も早い「決算短信」をまず確認し、より詳細な内容（事業のリスク情報や役員報酬の詳細など）を知りたい場合は、後日提出される「有価証券報告書」を確認する、という使い分けが一般的です。

### ひっかけポイント

各開示書類の「根拠法令（金融商品取引法か、取引所規則か、会社法か）」と「開示のタイミング（速報性）」の対応関係が問われやすいポイントです。特に2024年度の四半期報告書廃止という制度変更は、今後の出題で問われる可能性があるため押さえておきましょう。

## B-9：税務会計の基礎：益金と損金・課税所得と税額の計算・税効果会計

### 基本概念

会社が納める法人税等は、会計上の「利益」にそのまま税率をかけて計算するのではなく、税法上のルールで再計算した**課税所得**に税率をかけて計算します。

$$課税所得 = 益金 - 損金$$

「益金」は税法上の収益、「損金」は税法上の費用に近い概念ですが、企業会計上の「収益・費用」とは範囲が完全には一致しません。実務上は、会計上の「当期純利益」を出発点にして、会計と税法のズレを加減算する形で課税所得を計算します（申告調整）。ズレには4パターンがあります。

- **益金算入**：会計上は収益でないが税法上は益金になる → 加算
- **益金不算入**：会計上は収益だが税法上は益金にならない（例：受取配当金の一部）→ 減算
- **損金算入**：会計上は費用でないが税法上は損金になる → 減算
- **損金不算入**：会計上は費用だが税法上は損金にならない（例：交際費の一部、超過した減価償却費）→ 加算

このズレのうち、**将来において解消されるもの（一時差異）**については、**税効果会計**という手続きで調整します。一時差異には2種類あります。

- **将来減算一時差異**：今は税務上の利益（課税所得）が会計上の利益より多く、将来その差が解消するときに税金が減る効果を持つ差異 → **繰延税金資産**を計上
- **将来加算一時差異**：今は税務上の利益が会計上の利益より少なく、将来その差が解消するときに税金が増える効果を持つ差異 → **繰延税金負債**を計上

一方、交際費の損金不算入超過額や受取配当金の益金不算入額のように、**将来も永久に解消しない差異（永久差異）**は税効果会計の対象にはなりません（一時差異だけが対象です）。

### 具体例

法人税等の実効税率を30％とします。ある会社が、税務上は損金にできない「賞与引当金」を、前期末に3,000千円計上していました（会計上は費用だが、実際に支払うまでは税務上の損金にならない＝将来減算一時差異）。

前期末の繰延税金資産＝3,000千円×30％＝**900千円**

当期末に賞与引当金を3,300千円に増額した場合、当期末の繰延税金資産は3,300千円×30％＝**990千円**となり、前期末からの増加額は990千円－900千円＝**90千円**です。この90千円は、当期の損益計算書上「法人税等調整額」としてマイナス（税金費用を減らす方向）に計上されます。

もう少し発展的な例として、圧縮記帳（国庫補助金等を受け取った際に、その利益に対する課税を将来に繰り延べる制度）のうち「積立金方式」を使った場合を考えます。この方式では、会計上の資産の帳簿価額はそのままにしつつ、税務上だけ帳簿価額を圧縮するため、会計上の帳簿価額の方が税務上の帳簿価額より大きくなり、**将来加算一時差異**（＝繰延税金負債）が生じます。例えば圧縮記帳により将来加算一時差異が10,000千円生じた場合、繰延税金負債＝10,000千円×30％＝**3,000千円**となります。

### ひっかけポイント

「将来減算一時差異→繰延税金資産」「将来加算一時差異→繰延税金負債」という対応関係を、逆に覚えてしまうミスが非常に多い論点です。「将来、税金の支払いが減る（＝得をする）権利がある」から「資産」、「将来、税金の支払いが増える（＝損をする）義務がある」から「負債」、とイメージで結びつけると混同しにくくなります。また、税率が変わる場合（税制改正）は、繰延税金資産・負債の金額も新しい税率で再計算し直す点にも注意してください。

### 過去問で確認する
`problem_sets/1st_stage/exercises/B_finance_accounting_exercises.md` の「B-2：企業会計の基礎（税効果会計）」（実際にはB-9の税効果会計の論点に対応）を参照。将来減算一時差異・将来加算一時差異の判定と繰延税金資産・負債の計算過程を確認してください。

# 第2部：原価計算（B-10〜B-11）

原価計算とは、「製品やサービスを作るのに、いくらコストがかかったか」を計算する分野です。財務会計が「外部（株主・銀行）向けの報告」であるのに対し、原価計算は主に「社内の経営判断（値付け、生産計画、コスト管理）」に使われる情報を作る作業です。

## B-10：原価計算：原価概念・原価計算の種類と方法

### 基本概念

原価（コスト）は、まず次の3つの要素（**原価の3要素**）に分解できます。

- **材料費**：製品の材料そのものにかかる費用（例：パンの小麦粉代）
- **労務費**：製品を作る人にかかる費用（例：パン職人の給料）
- **経費**：材料費・労務費以外のコスト（例：工場の家賃、水道光熱費）

原価計算の方法には、目的に応じていくつかの分類軸があります。

| 分類軸 | 2つの方法 | 違い |
|---|---|---|
| 生産形態による分類 | **個別原価計算** vs **総合原価計算** | 個別受注生産（造船、建設）は個別原価計算、大量見込生産（食品、化学製品）は総合原価計算 |
| 原価の算定タイミングによる分類 | **実際原価計算** vs **標準原価計算** | 実際にかかったコストを事後的に集計するのが実際原価計算、あらかじめ目標となる原価（標準原価）を決めておき、実際原価との差異を分析するのが標準原価計算 |
| 固定費の扱いによる分類 | **全部原価計算** vs **直接原価計算** | 製造原価を変動費・固定費に分けずに全額を製品原価に含めるのが全部原価計算（財務諸表の作成に使う制度会計上の方法）。変動費だけを製品原価とし、固定費はその期の期間費用として扱うのが直接原価計算（社内の経営判断・CVP分析（B-15）に使う） |

### 具体例

パン屋が今月、小麦粉などの材料費200万円、パン職人の給料150万円、工場家賃50万円をかけて、10,000個のパンを作ったとします。原価の3要素はそれぞれ材料費200万円・労務費150万円・経費50万円で、合計400万円が今月の製造原価です。パン1個あたりの原価は400万円÷10,000個＝400円となります。もし来月から、大量生産する定番商品（食パン）と、少量ずつ受注生産する特注ケーキの両方を作るようになった場合、食パンは総合原価計算、特注ケーキは個別原価計算というように、製品の性質によって計算方法を使い分けます。

### ひっかけポイント

「全部原価計算・直接原価計算」の違いは、あくまで**固定費を製品原価に含めるかどうか**という一点に集約されます（全部＝含める、直接＝含めない）。財務諸表の作成には全部原価計算が使われる（直接原価計算は制度会計としては認められていない）一方、経営者が「これ以上生産すると儲かるか」を判断する場面（CVP分析など）では直接原価計算の考え方が使われる、という使い分けを混同しないようにしましょう。

---

## B-11：原価計算：原価情報の利用

### 基本概念

原価計算で集めた情報は、経営上の意思決定に活用します。代表的な考え方が次の2つです。

- **差額原価収益分析**：複数の選択肢を比較する際、どちらを選んでも変わらないコスト・収益は無視し、選択肢によって**変化する（差が出る）**コスト・収益だけに注目して判断する考え方
- **埋没原価（サンクコスト）**：既に支払ってしまい、どの選択肢を選んでも回収できない過去の支出。意思決定には影響させてはいけないコスト
- **機会原価**：ある選択肢を選んだことで、失ってしまった「他の選択肢を選んでいたら得られたはずの利益」

### 具体例

ある工場が、通常の生産ラインで手一杯の状況で「特別注文（追加1,000個、1個あたり300円で購入したいという申し出）」を受けるかどうか判断する場面を考えます。もしこの1,000個を作るための追加の変動費が1個あたり250円で、既存の生産に影響が出ない（遊休設備を使える）のであれば、固定費（工場家賃など、受注してもしなくても変わらないコスト）は判断に関係ない「埋没原価」に近い扱いとなり、1個あたり300円－250円＝50円の追加の儲け（限界利益）が生まれるため、受注すべきだと判断できます。逆に、この特別注文を受けることで、通常の生産ラインの一部を止めて既存顧客への納品が遅れるなら、失われる既存の利益（機会原価）も判断に含める必要があります。

### ひっかけポイント

「埋没原価は意思決定に影響させてはいけない」という原則を忘れ、既に支払った過去のコスト（例えば以前に購入して失敗した設備投資額）を「もったいないから」という理由で将来の判断に引きずってしまう誤り（サンクコストの誤謬）が典型的なひっかけです。判断すべきは常に「これから先、選択肢によって変わる差額のコスト・収益」だけです。

# 第3部：経営分析（B-12〜B-15）

経営分析は、貸借対照表・損益計算書という「過去の記録」から、会社の実力（儲ける力、安全性、効率性）を数値で読み解く分野です。ここからは、B-4・B-5で学んだ財務諸表の数値を使って、実際に指標を計算する練習をしていきます。

## B-12：経営分析：収益性分析（ROA、ROE、売上高利益率等）

### 基本概念

収益性分析は「会社がどれだけ効率よく儲けているか」を見る分析です。代表的な指標は次のとおりです（`docs/07_key_formulas_and_frameworks.md`と対応）。

- 売上高総利益率 ＝ 売上総利益 ÷ 売上高 × 100
- 売上高営業利益率 ＝ 営業利益 ÷ 売上高 × 100
- **ROA（総資産利益率）＝ 当期純利益（または経常利益）÷ 総資産 × 100**：会社が持つ資産全体を使って、どれだけ効率よく利益を生み出したか
- **ROE（自己資本利益率）＝ 当期純利益 ÷ 自己資本 × 100**：株主が出資したお金を使って、どれだけ効率よく利益を生み出したか

ROEは、次のように3つの要素に分解できます（デュポン分解と呼ばれる考え方）。

$$ROE = 売上高純利益率 \times 総資産回転率 \times 財務レバレッジ$$
$$\left(\frac{当期純利益}{自己資本}\right) = \left(\frac{当期純利益}{売上高}\right) \times \left(\frac{売上高}{総資産}\right) \times \left(\frac{総資産}{自己資本}\right)$$

この分解によって「ROEが高いのは、儲けの率が高いからか、資産を効率よく使っているからか、それとも借金（財務レバレッジ）を効かせているからか」を切り分けて分析できます。

### 具体例

ある会社の売上高が1億円、当期純利益が500万円、総資産が5,000万円、自己資本（純資産）が2,500万円だったとします。

- 売上高純利益率＝500万円÷1億円＝5％
- ROA＝500万円÷5,000万円×100＝**10％**
- ROE＝500万円÷2,500万円×100＝**20％**
- デュポン分解での検算：総資産回転率＝1億円÷5,000万円＝2回転、財務レバレッジ＝5,000万円÷2,500万円＝2倍
  → ROE＝5％×2回転×2倍＝**20％**（一致）

この会社は自己資本の2倍の総資産を（負債で）調達して事業を回しており、その財務レバレッジがROEを押し上げていることが分かります。

### ひっかけポイント

ROAは「総資産」に対する利益率であるのに対し、ROEは自己資本（総資産から負債を除いた部分）に対する利益率です。負債を多く使っている（財務レバレッジが高い）会社ほど、ROEはROAより大きく上振れしやすい点を理解しておきましょう。また、ROAの分子は「当期純利益」を使う場合と「経常利益」を使う場合があり、問題文の指示に必ず従う必要があります。

## B-13：経営分析：安全性分析（流動比率、自己資本比率等）

### 基本概念

安全性分析は「会社が倒産せずに、借金をきちんと返せる体力があるか」を見る分析です。代表的な指標は次のとおりです。

- **流動比率 ＝ 流動資産 ÷ 流動負債 × 100**：短期的な支払い能力を見る指標。一般に200％以上が望ましいとされる
- **当座比率 ＝ 当座資産 ÷ 流動負債 × 100**：流動資産のうち、すぐ現金化しやすい「当座資産」（現金預金、売掛金など。棚卸資産を除く）だけで、流動比率よりも厳しめに短期の支払い能力を見る指標
- **自己資本比率 ＝ 自己資本 ÷ 総資産 × 100**：総資産のうち、返済不要の自己資本がどれだけあるか。高いほど財務的に安定
- **固定比率 ＝ 固定資産 ÷ 自己資本 × 100**：固定資産（長期間使う資産）を、返済不要の自己資本でどれだけ賄えているか。低いほど望ましい
- **固定長期適合率 ＝ 固定資産 ÷ (自己資本＋固定負債) × 100**：固定比率よりやや緩やかに、固定資産を「自己資本＋長期の借入（固定負債）」でどれだけ賄えているかを見る指標

### 具体例

B-5で示したひまわりベーカリーの貸借対照表（流動資産1,300万円、流動負債500万円、固定資産2,000万円、固定負債1,000万円、純資産1,800万円、総資産3,300万円）を使って計算してみましょう。

- 流動比率＝1,300万円÷500万円×100＝**260％**（200％を超えており、短期の支払い能力は良好）
- 自己資本比率＝1,800万円÷3,300万円×100＝**約54.5％**
- 固定比率＝2,000万円÷1,800万円×100＝**約111.1％**（固定資産の一部は自己資本だけでは賄いきれておらず、固定負債にも依存している）
- 固定長期適合率＝2,000万円÷(1,800万円＋1,000万円)×100＝2,000万円÷2,800万円×100＝**約71.4％**（100％以下であり、固定資産は自己資本＋長期借入の範囲内で賄えている＝短期資金で固定資産を賄っていない、という安全な状態）

### ひっかけポイント

固定比率が100％を超えていても、固定長期適合率が100％以下であれば、直ちに危険というわけではありません（固定資産の一部を長期借入で賄うこと自体は一般的な財務戦略です）。むしろ危険なのは「固定長期適合率が100％を超えている」状態で、これは本来長期で保有すべき固定資産の一部を、短期の借入（流動負債）で賄っていることを意味し、資金繰りの安全性に懸念があると判断されます。分母・分子の組み合わせ（自己資本のみか、自己資本＋固定負債か）を正確に覚えておきましょう。

## B-14：経営分析：生産性・成長性分析

### 基本概念

**生産性分析**は「限られた経営資源（ヒト・モノ・カネ）から、どれだけ付加価値を生み出したか」を見る分析です。中心となる指標が**労働生産性**です。

$$労働生産性 = \frac{付加価値額}{従業員数}$$

「付加価値」とは、会社が外部から購入した材料・部品などに対して、自社が新たに付け加えた価値のことです。付加価値の計算方法には2つの考え方があります。

- **控除法**：付加価値 ＝ 売上高 － 外部購入価値（材料費・外注費など、社外から買ってきたコスト）
- **加算法**：付加価値 ＝ 経常利益 ＋ 人件費 ＋ 金融費用（支払利息等）＋ 賃借料 ＋ 租税公課 ＋ 減価償却費（会社の中で生み出され、関係者に分配された価値を積み上げる考え方）

**成長性分析**は「会社の規模が前年からどれだけ伸びたか」を見る分析です。

$$売上高増加率 = \frac{当期売上高 - 前期売上高}{前期売上高} \times 100$$

### 具体例

ある製造業の会社が、売上高3億円、外部購入価値（材料費・外注費）1億8,000万円、従業員数20人だったとします。

控除法による付加価値＝3億円－1億8,000万円＝**1億2,000万円**
労働生産性＝1億2,000万円÷20人＝**600万円／人**

前期の売上高が2億7,000万円だった場合、売上高増加率＝(3億円－2億7,000万円)÷2億7,000万円×100＝**約11.1％**となります。

### ひっかけポイント

労働生産性は「従業員1人あたりがどれだけ付加価値を生んでいるか」を示す指標であり、労働生産性が高いからといって従業員の給料（人件費）が高いとは限りません（利益として会社に残っている場合もあります）。控除法・加算法のどちらで付加価値を計算するかは問題文の指示に従う必要があり、両者は理論上一致するように設計されていますが、算入する費目（租税公課を含めるかどうか等）を混同しないよう注意しましょう。

## B-15：経営分析：CVP分析（損益分岐点分析）

### 基本概念

CVP分析（Cost-Volume-Profit分析、損益分岐点分析）は「売上高がいくらになれば利益がゼロになるか（損益分岐点）」を分析する手法で、原価を「変動費」（売上に比例して増減するコスト。材料費など）と「固定費」（売上に関係なく一定額かかるコスト。家賃など）に分解することが出発点になります。

- **限界利益 ＝ 売上高 － 変動費**（売上が1単位増えるごとに、固定費の回収・利益に貢献する部分）
- **限界利益率 ＝ (売上高 － 変動費) ÷ 売上高**
- **損益分岐点売上高 ＝ 固定費 ÷ 限界利益率**（利益がちょうどゼロになる売上高）
- **損益分岐点比率 ＝ 損益分岐点売上高 ÷ 実際売上高 × 100**（低いほど、余裕を持って黒字を確保できている）
- **安全余裕率 ＝ 1 － 損益分岐点比率**（実際の売上高が、損益分岐点からどれだけ離れているかの余裕度）

固定費の比率が高いか低いかを表す指標が**営業レバレッジ（度）＝限界利益 ÷ 営業利益**です。固定費比率が高い（＝営業レバレッジが高い）会社ほど、売上高が少し変動しただけで利益が大きく変動する「ハイリスク・ハイリターン」な費用構造になります。

### 具体例

ある飲食店の月間売上高が500万円、変動費（材料費など）が200万円、固定費（家賃・人件費など）が240万円だったとします。

- 限界利益＝500万円－200万円＝**300万円**
- 限界利益率＝300万円÷500万円＝**60％**
- 損益分岐点売上高＝240万円÷60％＝**400万円**
- 損益分岐点比率＝400万円÷500万円×100＝**80％**
- 安全余裕率＝1－80％＝**20％**
- 営業利益＝限界利益300万円－固定費240万円＝60万円 → 営業レバレッジ＝300万円÷60万円＝**5倍**

この店は売上高が実際の売上（500万円）から20％以上落ち込むと赤字に転落する、という余裕度が読み取れます。また営業レバレッジが5倍と高いため、売上高が10％増えれば利益はおよそ5倍の50％程度増える（逆に10％減れば利益も50％程度減る）という感応度の高さも分かります。

### ひっかけポイント

営業レバレッジが低い（固定費比率が低く、変動費中心の費用構造の）企業は、売上高が減少しても利益が減少しにくいという性質を持ちます。逆に「固定費を削減して変動費を増やす」と、営業レバレッジはむしろ**低下**します。また、一般に大規模な設備投資（固定費）を要する製造業の方が、仕入中心で変動費比率の高い小売業よりも営業レバレッジは高くなる傾向があります（逆に覚えないよう注意）。

### 過去問で確認する
`problem_sets/1st_stage/exercises/B_finance_accounting_exercises.md` の「B-15：CVP分析関連（営業レバレッジ）」を参照。

# 第4部：利益と資金の管理（B-16〜B-19）

「儲け（利益）」と「手元の現金（資金）」は別物です。利益が出ていても現金が足りずに倒産する（黒字倒産）ことすらあります。この章では、利益を計画的に生み出す方法と、資金繰りを管理する方法を学びます。

## B-16：利益と資金の管理：利益計画（限界利益、貢献利益、プロダクト・ミックス）

### 基本概念

複数の製品を作っている会社が、限られた生産能力（人手・機械の稼働時間など）をどの製品にどれだけ振り向けるべきか（**プロダクト・ミックス**）を決める際は、単純な「1個あたりの限界利益が高い製品を優先する」のではなく、**制約となっている資源（ボトルネック）1単位あたりの限界利益（貢献利益）が高い製品を優先する**、という考え方をします。

### 具体例

ある工場に、1日8時間（480分）しか使えない特殊な加工機械（ボトルネック）があり、製品Xと製品Yを作っているとします。

| | 製品X | 製品Y |
|---|---|---|
| 1個あたりの限界利益 | 1,000円 | 1,500円 |
| 1個あたりの機械使用時間 | 5分 | 10分 |
| 機械1分あたりの限界利益 | 1,000円÷5分＝**200円/分** | 1,500円÷10分＝**150円/分** |

1個あたりの限界利益だけを見ると製品Yの方が高く見えますが、ボトルネックである機械の稼働時間1分あたりで見ると製品Xの方が効率よく利益を生んでいます（200円/分 ＞ 150円/分）。したがって、機械の稼働時間が制約となっている場合は、製品Xを優先して生産すべきだと判断します。

### ひっかけポイント

「1個あたりの限界利益が高い製品を優先すべき」という単純な発想は、制約条件（ボトルネック）がある場合には誤りになります。必ず「制約となっている資源1単位あたりの限界利益（または貢献利益）」で比較する、という視点を持つことが重要です。

---

## B-17：利益と資金の管理：予算・実績差異分析

### 基本概念

会社は事前に立てた予算（標準原価等）と、実際の結果（実績）を比較し、その差（差異）がなぜ生じたのかを分析します。代表的なのが**標準原価計算における差異分析**で、材料費の差異は次の2つに分解します。

- **価格差異 ＝ (実際価格 － 標準価格) × 実際消費量**：仕入価格が予定と違ったことによる差異
- **数量差異 ＝ (実際消費量 － 標準消費量) × 標準価格**：材料の使用量が予定と違ったことによる差異

労務費についても同様に、賃率が予定と違ったことによる「賃率差異」と、作業時間が予定と違ったことによる「作業時間差異」に分解します。

### 具体例

ある製品の標準原価は「材料1kgあたり標準価格500円、1個あたり標準消費量2kg」と設定されていました。実際には、材料を1kgあたり520円で仕入れ、1個あたり2.2kg消費したとします。

- 価格差異＝(520円－500円)×2.2kg＝**44円（不利差異＝標準より多くコストがかかった）**
- 数量差異＝(2.2kg－2kg)×500円＝**100円（不利差異）**

このように分解することで、「仕入価格の上昇が原因なのか（購買部門の責任）」「材料を余計に使いすぎたのが原因なのか（製造部門の責任）」を切り分けて、改善につなげることができます。

### ひっかけポイント

価格差異は「実際価格と標準価格の差」に「実際消費量」を掛け、数量差異は「実際消費量と標準消費量の差」に「標準価格」を掛ける、という掛け合わせる数量（実際か標準か）の組み合わせを逆にしてしまうミスが頻出です。「価格のズレを測るときは、その価格で実際に使った量をそのまま掛ける」「数量のズレを測るときは、価格の変動要因を排除するため標準価格で固定して掛ける」とイメージで覚えると混同しにくくなります。

## B-18：利益と資金の管理：資金繰りと資金計画

### 基本概念

資金繰りとは、会社が事業を継続するために必要な現金を、いつ・いくら必要になるかを予測し、資金がショート（不足）しないように管理することです。特に重要なのが**運転資金**の考え方です。

$$運転資金 = 売上債権 + 棚卸資産 - 仕入債務$$

運転資金は「商品を仕入れてから、販売し、代金を回収するまでの間、会社が立て替えなければならない現金」のことです。売上が急拡大している会社ほど、売掛金や在庫が先に膨らみ、仕入代金の支払いも増えるため、運転資金の必要額が増加し、黒字であっても資金繰りが苦しくなることがあります（**黒字倒産**の典型パターン）。

### 具体例

ある卸売業の会社で、売上債権（売掛金）が2,000万円、棚卸資産（在庫）が1,500万円、仕入債務（買掛金）が1,200万円だったとします。

運転資金＝2,000万円＋1,500万円－1,200万円＝**2,300万円**

この会社は、売上が計上されてから実際に現金が入ってくるまでの間、2,300万円分の資金を自己資金や借入で立て替えておく必要がある、ということを意味します。事業が急拡大し、売上債権・棚卸資産がさらに膨らむと、この運転資金の必要額も増加するため、資金調達（B-20）をあらかじめ計画しておく必要があります。

### ひっかけポイント

「利益が出ている＝現金に余裕がある」とは限らない点が、資金繰り管理の核心です。特に売上が急成長している局面ほど運転資金の必要額が増え、資金がショートしやすいという「勘定合って銭足らず」の状況を理解しておきましょう。

---

## B-19：利益と資金の管理：キャッシュ・フロー管理（FCF、運転資金管理）

### 基本概念

**フリー・キャッシュフロー（FCF）**とは、会社が本業で稼いだ現金から、事業を維持・成長させるために必要な投資額を差し引いた、自由に使える現金のことです。

$$FCF = 営業キャッシュ・フロー - 投資キャッシュ・フロー（または設備投資額）$$

FCFがプラスであれば、借入の返済や株主への配当、新規投資の原資に使える余裕があることを意味します。FCFの計算では、B-6で学んだ間接法の考え方（当期純利益に非資金費用を加算し、運転資本の増減を調整する）がベースになります。

キャッシュ・フローの効率性を測る指標として**キャッシュ・コンバージョン・サイクル（CCC）**があります。

$$CCC = 売上債権回転日数 + 棚卸資産回転日数 - 仕入債務回転日数$$

CCCは「仕入代金を支払ってから、販売代金を回収するまでに何日かかるか」を表し、日数が短いほど、少ない運転資金で事業を回せている（資金効率が良い）ことを意味します。

### 具体例

税金は存在しないと仮定します。当期純利益が1,000万円、減価償却費（非資金費用）が200万円、売上債権が150万円増加、仕入債務が80万円増加、設備投資額が300万円だったとします。

1. 営業CF＝1,000万円＋200万円（減価償却費を加算）－150万円（売上債権増加を減算）＋80万円（仕入債務増加を加算）＝**1,130万円**
2. FCF＝営業CF1,130万円－設備投資額300万円＝**830万円**

このように、売上債権の増加（現金回収の遅れ）はFCFにマイナスに、仕入債務の増加（支払いの先延ばし）はFCFにプラスに働きます。設備投資額そのものは、当期純利益の計算には出てきませんが、実際に現金が出ていく支出なので必ず差し引く必要があります。

### ひっかけポイント

「売上債権の増加額は当期純利益に加算される」「減価償却費は当期純利益から減算される」「設備投資額は当期純利益に加算される」といった記述は、いずれもB-6で説明した加減算の向きを逆にした典型的な誤りです。売上債権増加→減算、減価償却費→加算、設備投資額→減算（現金支出そのもの）という向きを正確に押さえましょう。

# 第5部：資金調達と配当政策（B-20〜B-23）

会社が事業を行うには元手（資金）が必要です。この章では「どこからお金を集めるか」「集めたお金にはどれだけコストがかかっているか」「儲けをどう配分するか」「借金と自己資本のバランスをどう考えるか」を学びます。この分野は2次試験の事例IVにも直結する重要分野です。

## B-20：資金調達と配当政策：資金調達の形態（内部・外部、直接・間接金融）

### 基本概念

資金調達の方法は、次の2つの軸で整理できます。

| 軸 | 分類 | 内容 |
|---|---|---|
| 調達元による分類 | **内部金融** | 会社の内部から生み出す資金（内部留保、減価償却費など） |
| | **外部金融** | 会社の外部から調達する資金（増資、借入、社債発行など） |
| 資金の流れによる分類 | **直接金融** | 株式や社債を発行し、投資家から直接資金を調達する方法 |
| | **間接金融** | 銀行などの金融機関を介して（銀行が投資家から集めた預金を原資に）資金を調達する方法（銀行借入） |

### 具体例

ある会社が新工場を建てるために、①これまで貯めてきた利益（内部留保）を取り崩す、②銀行から融資を受ける、③新株を発行して投資家から出資を募る、という3つの選択肢を検討しているとします。①は内部金融、②は間接金融（銀行という金融機関を介するため）、③は直接金融（投資家から直接資金を集めるため）に分類されます。

### ひっかけポイント

「銀行借入」は外部金融であると同時に間接金融です。「社債発行」は外部金融であると同時に直接金融です。「外部金融＝間接金融」と誤って結びつけないよう、2つの軸（内部・外部／直接・間接）は独立した分類であることを意識してください。

---

## B-21：資金調達と配当政策：資本コスト（負債・自己資本・WACC）

### 基本概念

会社が資金を調達するには、必ず「コスト」がかかります。借入をすれば利息を払う必要があり（負債コスト）、株式を発行すれば株主が期待するリターンに応えなければなりません（自己資本コスト）。

- **負債コスト**：借入の利率（負債利子率）そのもの。ただし、支払利息は税務上損金に算入できる（節税効果がある）ため、実質的な負債コストは「税引前負債コスト×(1－実効税率)」という**税引後**の金額で考えます。
- **自己資本コスト**：株主が期待するリターン。配当割引モデル（B-30で詳しく学びます）を使う場合は「自己資本コスト＝1株当たり予想配当 ÷ 株価」（成長率ゼロの場合）で計算したり、CAPM（B-29で詳しく学びます）を使う場合は「自己資本コスト＝リスクフリーレート＋β×市場リスクプレミアム」で計算したりします。

会社全体としての資金調達コストは、負債コストと自己資本コストを、それぞれの調達額（時価）の割合で加重平均した**加重平均資本コスト（WACC）**で表します。

$$WACC = 負債コスト \times (1-実効税率) \times \frac{負債}{総資本} + 自己資本コスト \times \frac{自己資本}{総資本}$$

WACCは、会社が新しい投資プロジェクトを行うかどうかを判断する際の「最低限クリアすべき収益率（ハードルレート）」として使われます（B-24〜B-26のNPV法・IRR法の割引率として登場します）。

### 具体例

ある会社の負債（時価）が5,000万円、株主資本（時価）が5,000万円、発行済株式数が100万株、毎期の1株当たり配当金が5円、税引前の負債コストが4％、法人税等の実効税率が30％だったとします（配当割引モデルで、配当は毎期一定と仮定）。

1. 株価＝株主資本の時価5,000万円÷発行済株式数100万株＝**50円**
2. 自己資本コスト（配当割引モデル）＝1株当たり配当5円÷株価50円＝**10％**
3. 税引後負債コスト＝税引前負債コスト4％×(1－実効税率30％)＝**2.8％**
4. 総資本＝負債5,000万円＋株主資本5,000万円＝1億円、負債の割合＝0.5、自己資本の割合＝0.5
5. WACC＝2.8％×0.5＋10％×0.5＝1.4％＋5％＝**6.4％**

### ひっかけポイント

負債コストを税引後にせず、そのまま(税引前の値で)加重平均してしまう計算ミスが最頻出です。必ず「負債コスト×(1－実効税率)」の税引後の値を使ってください。また、負債が増えるほど倒産（債務不履行）の可能性が高まり、それに応じて負債の資本コストにも「リスクプレミアム」が上乗せされます。株主資本コストについても、負債を利用している企業では「リスクフリー・レート＋事業リスクプレミアム＋財務リスクプレミアム（負債利用による上乗せ分）」という構成になり、財務リスクプレミアムだけで構成されるわけではない点にも注意してください。

## B-22：資金調達と配当政策：ペイアウト政策（配当政策、自社株買い）

### 基本概念

会社が稼いだ利益を、どのように株主に還元するか（**ペイアウト政策**）には主に2つの方法があります。

- **配当**：利益の一部を現金で株主に分配する
- **自社株買い**：会社が市場に出回っている自社の株式を買い戻す。発行済株式数が減るため、1株当たり利益（EPS）や1株当たり純資産（BPS）が向上する効果がある

利益のうち、どれだけを配当に回すかを示す指標が**配当性向 ＝ 配当金総額 ÷ 当期純利益 × 100**です。残りは内部留保として会社に蓄積され、将来の投資の原資になります。

MM理論（B-23で詳しく学びます）の考え方を配当政策に当てはめると、完全資本市場（税金や取引コストがない理想的な市場）を仮定した場合、配当を多く出すか内部留保するかは、理論上は企業価値に影響を与えない（配当無関連命題）とされます。ただし現実には、税金の違い（配当への課税と株式売却益への課税の違い）や、配当が会社の将来性についてのシグナルとして市場に受け取られる効果（シグナリング効果）などから、配当政策は実務上重要な意思決定です。

### 具体例

ある会社の当期純利益が10億円、発行済株式数が1,000万株だったとします。配当金総額を3億円とした場合、配当性向＝3億円÷10億円×100＝**30％**です。もしこの会社が、配当を増やす代わりに3億円で自社株買いを行い、発行済株式数を100万株分（1割）買い戻して消却した場合、発行済株式数は900万株に減少し、1株当たり利益（EPS＝当期純利益÷発行済株式数）は10億円÷1,000万株＝100円から、10億円÷900万株≒111円へと上昇します。

### ひっかけポイント

自社株買いは「株主への還元」という点で配当と似た効果を持ちますが、現金を直接受け取る配当とは異なり、株価の上昇（1株当たり利益・純資産の向上）という形で株主に還元される点が異なります。配当性向が高い＝良い会社、と単純に判断するのではなく、成長投資のために内部留保を優先する会社もある、という多面的な理解が必要です。

## B-23：資金調達と配当政策：最適資本構成（財務レバレッジ、MM理論）

### 基本概念

会社の資金調達における「負債と自己資本の組み合わせ（資本構成）」が、企業価値にどう影響するかを説明する理論が**MM理論（モジリアーニ・ミラーの定理）**です。

- **MM理論（法人税がない完全資本市場を仮定した場合）**：資本構成（負債と自己資本の比率）を変えても、企業価値は変化しない（無関連命題）。負債比率が高まると財務リスクが上昇し自己資本コストが上がる一方、コストの低い負債の割合が増えるため、両者が相殺し合いWACCは資本構成にかかわらず一定になる、と説明されます。
- **法人税がある場合の修正MM理論**：負債の支払利息には節税効果（損金算入による税負担の軽減）があるため、負債を増やすほど（節税効果の分だけ）企業価値は増加すると修正されます。
- **トレードオフ理論**：現実には、負債を増やしすぎると倒産の可能性が高まり、それに伴う倒産コスト（信用低下、取引先の離反など）も増加します。「負債の節税効果」と「倒産コストの増加」がちょうど釣り合う点に、企業にとっての**最適資本構成**が存在する、と考えるのがトレードオフ理論です。

**財務レバレッジ**とは、負債を利用することで自己資本に対する利益率（ROE）を高める効果のことです（B-12のデュポン分解での「総資産÷自己資本」の部分に対応します）。

### 具体例

ある会社が、総資産10億円の事業に投資し、総資産営業利益率（事業そのものの利回り）が8％だったとします。全額自己資本（負債ゼロ）で調達した場合と、半分を負債（借入利率4％）で調達した場合を比較します（税金は無視）。

- **全額自己資本の場合**：営業利益＝10億円×8％＝8,000万円。ROE＝8,000万円÷10億円（自己資本）＝**8％**
- **自己資本5億円＋負債5億円の場合**：営業利益は変わらず8,000万円。支払利息＝5億円×4％＝2,000万円。株主に残る利益＝8,000万円－2,000万円＝6,000万円。ROE＝6,000万円÷5億円（自己資本）＝**12％**

事業の利回り（8％）が負債の利率（4％）を上回っているため、負債を利用することでROEが8％から12％に押し上げられています。これが財務レバレッジの効果です（逆に、事業の利回りが借入利率を下回る局面では、負債の利用がROEを押し下げる方向に働きます）。

### ひっかけポイント

「負債を増やせば増やすほど、無条件にROEが上がり企業価値も上がる」という理解は誤りです。MM理論（無税の場合）では資本構成は企業価値に無関連であり、法人税を考慮しても、負債を増やしすぎれば倒産リスク・倒産コストの増加という副作用がある（トレードオフ理論）点を忘れないようにしましょう。財務レバレッジは「事業の利回り＞負債の利率」のときにのみROEを押し上げる、という条件付きの効果である点も重要です。

# 第6部：実物投資（B-24〜B-27）

実物投資とは、工場・設備・新規事業などへの投資判断のことです。「今、お金を投じて、将来にわたって得られるキャッシュフローが、その投資に見合うだけの価値があるか」を判定する分野で、2次試験事例IVの計算問題の中心テーマでもあります。

## B-24：実物投資：貨幣の時間価値とDCF

### 基本概念

「今日の100万円」と「1年後の100万円」は、同じ金額でも価値が異なります。今日の100万円は、今すぐ運用に回せば1年後には利息がついて増えているはずだからです。この考え方を**貨幣の時間価値**と呼びます。将来のお金を「今の価値」に割り引いて評価する手法が**DCF（Discounted Cash Flow、割引キャッシュフロー）法**です。

割引率（資本コスト）を$r$、$n$年後に受け取るキャッシュフローを$CF_n$とすると、その現在価値は次の式で計算します。

$$現在価値 = \frac{CF_n}{(1+r)^n}$$

試験では、$\frac{1}{(1+r)^n}$の値をあらかじめ計算した「複利現価係数表」が与えられることが多く、現在価値＝将来のキャッシュフロー×複利現価係数、という掛け算で計算できます。

### 具体例

割引率（資本コスト）が6％のとき、2年後に受け取る220万円の現在価値を考えます。複利現価係数表で2年・6％の係数が0.88と与えられている場合、

現在価値＝220万円×0.88＝**193.6万円**

つまり「2年後の220万円」は、割引率6％の世界では「今の193.6万円」と同じ価値だと評価されます。割引率が高いほど、また将来の期間が長いほど、現在価値は小さくなる（＝将来のお金の価値は割り引かれる）という感覚をつかんでおきましょう。

### ひっかけポイント

複利現価係数表が与えられる問題では、係数と金額の掛け算自体は単純ですが、「何年後のキャッシュフローに、何年の係数を掛けるか」を取り違えるミスが多発します。キャッシュフローが発生するタイミング（期首か期末か、何年目か）を必ずタイムラインで整理してから計算するようにしましょう。

## B-25：実物投資：投資評価基準（回収期間法、会計的投資利益率法）

### 基本概念

投資評価には、貨幣の時間価値を考慮しない簡便な方法もあります。

- **回収期間法**：投資額を、その投資から得られるキャッシュフローで何年かけて回収できるかを計算する方法。回収期間が短いほど良いと判断する。計算が簡単な反面、貨幣の時間価値を考慮しない、回収後のキャッシュフローを無視する、という欠点がある
- **会計的投資利益率法（ARR：Accounting Rate of Return）**：会計上の利益を基準にした投資利益率。$ARR = \frac{平均年間利益}{平均投資額（または初期投資額）} \times 100$で計算する。こちらもキャッシュフローではなく会計上の利益を使うため、貨幣の時間価値を考慮しない簡便法である点は回収期間法と共通する

### 具体例

初期投資額が1,000万円で、毎年200万円のキャッシュフローが得られる投資案の場合、回収期間＝1,000万円÷200万円＝**5年**です。もし別の投資案Bが、初期投資額600万円で毎年150万円のキャッシュフローが得られるなら、回収期間＝600万円÷150万円＝**4年**となり、単純な回収期間法で比較すると投資案Bの方が優先されます。

### ひっかけポイント

回収期間法・会計的投資利益率法は、いずれも「貨幣の時間価値を考慮しない」という共通の弱点を持ちます。「5年目以降にどれだけ稼ぐか」という情報を無視してしまうため、長期的に見ると本来より有利な投資案を過小評価してしまう可能性がある点を理解しておきましょう。より精緻な評価には、次のB-26で学ぶNPV法・IRR法（貨幣の時間価値を考慮する方法）を使います。

---

## B-26：実物投資：投資評価基準（IRR法、NPV法、収益性指数法）

### 基本概念

貨幣の時間価値を考慮した、より精緻な投資評価方法です。

- **正味現在価値法（NPV：Net Present Value）**：投資から得られる将来のキャッシュフローを現在価値に割り引いた合計額から、初期投資額を差し引いた金額。$NPV = \sum \frac{CF_n}{(1+r)^n} - 初期投資額$。**NPV＞0であれば、その投資は実行すべき**と判断する
- **内部収益率法（IRR：Internal Rate of Return）**：NPVがちょうどゼロになる割引率のこと。その投資案が生み出す実質的な利回りを意味する。**IRR＞資本コストであれば、その投資は実行すべき**と判断する
- **収益性指数法（PI：Profitability Index）**：$PI = \frac{将来キャッシュフローの現在価値}{初期投資額}$。**PI＞1であれば、その投資は実行すべき**と判断する（投資額に対する効率性で複数案を比較するときに有効）

### 具体例

ある投資案は、初期投資額2,200万円（第1期首に投資）、第1期末のキャッシュフローが1,100万円、第2期末のキャッシュフローが2,200万円、資本コストが6％（複利現価係数：1年＝0.94、2年＝0.88）だったとします（税金は無視）。

NPV＝－2,200万円＋1,100万円×0.94＋2,200万円×0.88
　＝－2,200万円＋1,034万円＋1,936万円
　＝－2,200万円＋2,970万円
　＝**770万円**

NPVが770万円とプラスなので、この投資案は実行すべきだと判断します。同じキャッシュフローを使って収益性指数を計算すると、PI＝2,970万円（将来CFの現在価値の合計）÷2,200万円（初期投資額）＝**約1.35**となり、こちらも1を超えているため投資に値すると判断できます。

### ひっかけポイント

NPV法とIRR法は、単独の投資案の採否を判断する場面では同じ結論になることが多いですが、**投資規模が大きく異なる複数の投資案を比較する場合には、NPVとIRRで優劣の判断が逆転することがある**点に注意が必要です（IRRは「率」であり投資規模を考慮しないため）。企業価値の最大化という観点からは、一般にNPV法の方が優れた判断基準とされています。また、現価係数表を使う計算問題では、初期投資額（現在価値そのまま、割り引く必要がない）と将来のキャッシュフロー（割り引く必要がある）を混同しないようにしましょう。

## B-27：実物投資：不確実性下の投資決定

### 基本概念

将来のキャッシュフローは不確実性を伴います。この不確実性を投資判断に織り込む代表的な考え方に、次のものがあります。

- **期待値法**：将来起こりうる複数のシナリオ（好況・不況など）それぞれの発生確率とキャッシュフローを見積もり、その加重平均（期待値）を使ってNPV等を計算する方法
- **感応度分析**：売上高や原価などの前提条件を変化させたとき、投資評価の結果（NPV等）がどれだけ変化するかを分析し、どの変数がリスクの主な要因かを把握する方法
- **デシジョンツリー（意思決定樹）分析**：複数の意思決定のタイミングと、それぞれの分岐で発生しうる不確実な事象を樹形図に整理し、期待値を計算しながら最適な意思決定の経路を探る方法

### 具体例

ある新製品の投資案について、市場が好況になる確率が60％で得られるキャッシュフローが3,000万円、不況になる確率が40％で得られるキャッシュフローが500万円と見積もられたとします。

期待キャッシュフロー＝3,000万円×60％＋500万円×40％＝1,800万円＋200万円＝**2,000万円**

この期待キャッシュフロー2,000万円を使ってNPVを計算し、投資の採否を判断します。

### ひっかけポイント

期待値だけで判断すると、実際に発生しうる「最悪のシナリオでどれだけ損失が出るか」というリスクの大きさが見えなくなる点に注意が必要です。期待値が同じでも、シナリオごとのばらつき（リスク）が大きい投資案と小さい投資案では、慎重な意思決定者は後者を選好する場合がある、という視点も押さえておきましょう。

# 第7部：証券投資（B-28〜B-29）

これまでは会社側（発行体）から見た資金調達・投資の話でしたが、ここからは投資家側から見た「株式・債券などの証券に投資する」際の考え方を学びます。

## B-28：証券投資：ポートフォリオ理論

### 基本概念

**ポートフォリオ理論**は「複数の証券に分散して投資することで、リスクを減らせる」という考え方を数学的に整理した理論です。証券投資の world では、リターン（収益率）の平均値を「期待収益率」、リターンのばらつきの大きさを「リスク（標準偏差）」と呼びます。

複数の証券を組み合わせたとき、ポートフォリオ全体のリスクは、個々の証券のリスクを単純に平均した値より小さくなることがあります。これを**分散投資効果**と呼びます。分散投資効果の大きさは、組み合わせる証券同士の値動きの連動性を表す**相関係数**（－1から＋1の値をとる）によって決まります。

- 相関係数が＋1（完全に同じ値動き）に近いほど → 分散投資効果は小さい（リスクはほとんど減らない）
- 相関係数が－1（完全に逆の値動き）に近いほど → 分散投資効果は大きい（リスクを大きく減らせる）

ただし、どれだけ多くの銘柄に分散しても、市場全体が同じ方向に動くことによるリスク（**市場リスク・システマティック・リスク**）は消すことができません。分散によって消えるのは、個別銘柄固有の事情によるリスク（**個別リスク・非システマティック・リスク**）だけです。

### 具体例

「傘メーカーの株式」と「日焼け止めメーカーの株式」を考えてみましょう。雨の日が多い年は傘メーカーの業績が良くなる一方、日焼け止めメーカーの業績は悪くなりがちです（逆に、晴天が多い年はその逆）。この2社の株価は相関係数がマイナスに近い関係にあると考えられ、両方に分散投資することで、天候というリスク要因に対する影響を打ち消し合い、ポートフォリオ全体のリスクを1社だけに投資するよりも小さくできます。

### ひっかけポイント

「分散投資をすればリスクはゼロにできる」というのは誤りです。分散投資で消せるのは個別リスクだけであり、市場全体が動くことによる市場リスクは、どれだけ銘柄数を増やしても残り続けます。この「消せないリスク（市場リスク）」に対する感応度を測る指標が、次のB-29で学ぶ「β（ベータ）」です。

---

## B-29：証券投資：資本市場理論（効率的市場仮説、CAPM）

### 基本概念

**効率的市場仮説**とは、株式市場において、入手可能な情報はすぐに株価に反映されるため、その情報を使って継続的に市場平均を上回るリターン（超過収益）を得ることはできない、という考え方です。効率性の強さは3段階に分けられます。

| 段階 | 反映される情報 | 意味 |
|---|---|---|
| **ウィーク型** | 過去の株価・出来高の情報 | 過去の値動きを分析（テクニカル分析）しても超過収益は得られない |
| **セミストロング型** | 公表されている全ての情報（決算発表等） | 公開情報の分析（ファンダメンタルズ分析）をしても超過収益は得られない |
| **ストロング型** | 未公表の内部情報も含む全ての情報 | インサイダー情報を使っても超過収益は得られない |

分散投資（B-28）をしても消せない「市場リスク」に対して、投資家がどれだけの追加リターンを要求するかをモデル化したのが**CAPM（Capital Asset Pricing Model、資本資産評価モデル）**です。

$$自己資本コスト（期待収益率） = リスクフリー・レート + \beta \times (市場全体の期待収益率 - リスクフリー・レート)$$

ここで「$市場全体の期待収益率 - リスクフリー・レート$」を**市場リスクプレミアム**と呼びます。**β（ベータ）**は、個別銘柄の値動きが市場全体の値動きに対してどれだけ感応度が高いかを表す指標で、市場ポートフォリオ全体のβは1、無リスク資産（国債など）のβは0です。βが1より大きい銘柄は市場平均より値動きが大きい（ハイリスク・ハイリターン）銘柄、βが1より小さい銘柄は値動きが小さい（ローリスク・ローリターン）銘柄と解釈します。

### 具体例

リスクフリー・レートが2％、市場全体の期待収益率が8％、ある会社の株式のβが1.5だったとします。

自己資本コスト＝2％＋1.5×(8％－2％)＝2％＋1.5×6％＝2％＋9％＝**11％**

この会社の株式は、市場平均より値動きが大きい（β＞1）ため、投資家はリスクフリー・レートよりもかなり高い11％のリターンを要求している、と解釈できます。

### ひっかけポイント

「株主資本コストのリスクプレミアムには市場リスクが反映されていない」という記述は誤りです。CAPMの式そのものが「リスクフリー・レート＋β×市場リスクプレミアム」という形で、市場リスクを明確に組み込んでいます。効率的市場仮説の3段階（ウィーク・セミストロング・ストロング）についても、それぞれどの情報まで株価に反映されているかという範囲の違いを正確に区別しましょう。

# 第8部：企業価値（B-30〜B-32）

企業価値とは「その会社全体、あるいはその会社の株式全体が、いくらの価値を持つか」を評価する分野です。株式投資やM&Aの場面で使われる考え方で、B-24〜B-29で学んだ「割引現在価値」の考え方の応用編にあたります。

## B-30：企業価値：株主価値の算定（配当割引モデル、PER、PBR）

### 基本概念

株主にとっての企業価値（株価）を算定する代表的な方法が**配当割引モデル（DDM：Dividend Discount Model）**です。株式の価値は、将来受け取る配当を、株主資本コストで割り引いた現在価値の合計だと考えます。配当が毎期一定率$g$で成長し続けると仮定するモデル（定率成長モデル、ゴードン・モデル）では次の式になります。

$$株価 = \frac{来期予想配当}{株主資本コスト - 配当成長率}$$

実務でよく使われる簡便な株価指標には、次の2つがあります。

- **PER（株価収益率）＝ 株価 ÷ 1株当たり利益（EPS）**：株価が1株当たり利益の何倍まで買われているかを示す。低いほど割安と判断されることが多い
- **PBR（株価純資産倍率）＝ 株価 ÷ 1株当たり純資産（BPS）**：株価が1株当たり純資産（会社の解散価値に近い概念）の何倍まで買われているかを示す。PBRが1倍を下回る場合、理論上は会社を解散して純資産を分配した方が株価より高い価値になる、という状態を意味する

### 具体例

ある会社の来期の予想配当が1株当たり30円、株主資本コストが8％、配当成長率が3％だと見積もられたとします。

株価＝30円÷(8％－3％)＝30円÷5％＝**600円**

また、この会社の1株当たり利益（EPS）が50円、1株当たり純資産（BPS）が400円だとすると、実際の株価が600円である場合、PER＝600円÷50円＝**12倍**、PBR＝600円÷400円＝**1.5倍**と計算できます。

### ひっかけポイント

配当割引モデルの分母は「株主資本コスト－配当成長率」であり、配当成長率が株主資本コストを上回る（分母がマイナスになる）ケースは理論上想定されない（成長率は資本コストより低いことが前提）点に注意してください。また、PER・PBRは業種や成長性によって適正水準が大きく異なるため、単純に「低ければ割安、高ければ割高」と機械的に判断できるわけではない、という限界も理解しておきましょう。

---

## B-31：企業価値：企業価値評価モデル（残余利益、DCF）

### 基本概念

会社全体の価値（企業価値）を評価する代表的な方法に、次の2つがあります。

- **DCF法（企業価値版）**：会社が将来生み出すフリー・キャッシュフロー（FCF）を、WACC（B-21）で割り引いた現在価値の合計を「事業価値」とし、そこに現預金など事業に直接使っていない資産（非事業用資産）を加えたものを「企業価値」とする方法。さらに企業価値から有利子負債を差し引いたものが、株主に帰属する「株主価値」になる（$株主価値 = 企業価値 - 有利子負債$）
- **残余利益モデル（RIM：Residual Income Model）**：会計上の利益から、投下した自己資本に対する期待リターン（資本コスト相当額）を差し引いた「残余利益（超過利益）」に着目し、現在の純資産額に、将来の残余利益の現在価値を加算することで株主価値を算定する方法。会計上の利益（帳簿の数値）をベースにできる点がDCF法との違い

### 具体例

ある会社の将来のFCFの現在価値の合計（事業価値）が20億円、現預金など非事業用資産が3億円、有利子負債が8億円だったとします。

企業価値＝事業価値20億円＋非事業用資産3億円＝**23億円**
株主価値＝企業価値23億円－有利子負債8億円＝**15億円**

発行済株式数が1,000万株であれば、理論株価＝15億円÷1,000万株＝**150円**と算定できます。

### ひっかけポイント

「企業価値」と「株主価値」を混同しないようにしましょう。企業価値は「事業全体（株主＋債権者の取り分の合計）」の価値であるのに対し、株主価値はそこから有利子負債（債権者の取り分）を差し引いた、株主だけの取り分です。M&A（B-32）の場面で「買収額」を議論する際、企業価値ベースの金額なのか株主価値ベースの金額なのかを取り違えると、判断を大きく誤ります。

---

## B-32：企業価値：M&Aにおける企業評価（収益還元、純資産、乗数法）

### 基本概念

M&A（合併・買収）の際、買収対象の企業価値をどう評価するかについて、代表的な3つのアプローチがあります。

- **コストアプローチ（純資産方式）**：対象会社の貸借対照表上の純資産（簿価、または時価に評価し直した時価純資産）を基準に企業価値を評価する方法。計算がシンプルで客観的だが、将来の収益力を反映しにくいという弱点がある
- **マーケットアプローチ（類似会社比較法・乗数法）**：類似する上場企業の株価指標（PER、PBR、EBITDA倍率など）を参考にして、対象会社の利益や純資産に一定の倍率（マルチプル）を掛けて評価する方法
- **インカムアプローチ（収益還元法・DCF法）**：対象会社が将来生み出す利益・キャッシュフローを基準に評価する方法。DCF法（B-31）のほか、毎期一定の利益が続くと仮定して、その利益を資本還元率で割り戻す「収益還元法」がある

### 具体例

対象会社の直近の税引後利益が毎期安定して2,000万円続くと見込まれ、資本還元率（要求利回り）を10％とする場合、収益還元法による企業価値＝2,000万円÷10％＝**2億円**と算定できます。同じ会社の貸借対照表上の時価純資産が1億5,000万円だった場合（コストアプローチ）、両者の間に差（のれん相当額）が生じますが、これはこの会社が持つ超過収益力（ブランド力、顧客基盤など）を反映していると解釈できます。

### ひっかけポイント

3つのアプローチはそれぞれ異なる前提・視点に基づいており、同じ会社でも評価額が一致するとは限りません。実務のM&Aでは、これら複数の手法を併用し、評価額に幅を持たせて交渉の土台とすることが一般的です。「どれか1つの正しい企業価値がある」という発想ではなく、「アプローチによって評価額は変わりうる」という前提を理解しておきましょう。

# 第9部：デリバティブとリスク管理（B-33〜B-34）

デリバティブとは、株式・為替・金利などの「原資産」の値動きから派生して価値が決まる金融商品のことです。企業が為替変動や金利変動のリスクをヘッジ（回避）する目的でよく使われます。

## B-33：デリバティブとリスク管理：オプション取引（コール、プット）

### 基本概念

オプション取引とは、「将来のある期日（または期間内）に、あらかじめ決めた価格（権利行使価格）で、原資産を売買する『権利』」を売買する取引です。

- **コール・オプション**：原資産を、あらかじめ決めた価格で「買う権利」
- **プット・オプション**：原資産を、あらかじめ決めた価格で「売る権利」

この権利を得るために支払う対価が**オプション料（プレミアム）**で、次の2つの要素で構成されます。

$$オプション料（プレミアム） = 本質的価値 + 時間的価値$$

- **本質的価値**：今すぐ権利行使した場合に得られる価値（原資産価格と権利行使価格の差額）。ゼロになることはあっても、マイナスになることはない
- **時間的価値**：満期までの時間があることによる「将来値上がり（値下がり）するかもしれない」という期待に基づく価値。満期に近づくほど小さくなり、満期時点ではゼロになる

コール・オプションの買い手は、原資産価格が上昇するほど利益が大きくなりますが、損失は最大でも支払ったプレミアムに限定される（権利を放棄すればよいだけなので）という非対称性が特徴です。

### 具体例

ある株式のコール・オプション（権利行使価格1,000円、プレミアム50円）を購入したとします。満期時点の株価が1,200円になった場合、権利行使して1,000円で株式を買い、市場で1,200円で売れば200円の差益が得られ、支払ったプレミアム50円を差し引いた150円が利益になります。逆に満期時点の株価が900円（権利行使価格を下回る）だった場合、権利を行使せずに放棄すればよく、損失は支払ったプレミアム50円に限定されます（コール・オプションの本質的価値は、原資産価格が権利行使価格を下回るときはゼロになり、マイナスにはなりません）。

### ひっかけポイント

オプションの「買い手」の損失は、常にプレミアム（オプション料）に限定される一方、オプションの「売り手」は、相手が権利行使すれば理論上無限大の損失を被る可能性がある、という非対称なリスク構造を理解しておきましょう。中小企業がリスクヘッジの目的で利用する場合は、基本的に「コール・プットの買い」が中心になります（プレミアムを支払うだけで、損失を限定しながらリスクヘッジができるため）。

---

## B-34：デリバティブとリスク管理：先物取引・スワップ

### 基本概念

- **先物取引**：将来のある期日に、あらかじめ決めた価格・数量で原資産を売買することを、現時点で約束する取引。オプション取引と異なり、権利ではなく「義務」であるため、期日には必ず売買を実行しなければならない（途中で反対売買により決済することも可能）
- **為替予約**：外国為替の先物取引の一種。将来の外貨受け払いのレートをあらかじめ固定することで、為替変動リスクを回避（ヘッジ）する目的でよく使われる
- **スワップ取引**：将来にわたって発生する2つのキャッシュフローを、当事者間で交換する取引。代表的なものに、同一通貨の異なるタイプの金利（固定金利と変動金利など）を交換する**金利スワップ**、異なる通貨間で元本と金利の両方を交換する**通貨スワップ**がある

### 具体例

輸出企業が、3か月後に1万ドルの輸出代金を受け取る予定があるとします。現在の為替レートは1ドル150円ですが、3か月後に円高（例えば1ドル140円）になっていると、受取額が日本円換算で150万円から140万円に目減りしてしまいます。そこで、あらかじめ「3か月後に1ドル148円で円に交換する」という為替予約を金融機関と結んでおけば、3か月後の実際の為替レートがいくらであっても148万円を確定させることができ、為替変動リスクを回避できます。

また、変動金利で借入をしている会社が、今後の金利上昇を懸念する場合、固定金利を支払い変動金利を受け取る金利スワップ契約を結ぶことで、実質的に「固定金利での借入」に切り替えたのと同じ効果を得ることができます。

### ひっかけポイント

先物取引・為替予約は「義務」であり、将来の価格が予約時点より有利な方向に動いた場合でも、予約したレート・価格での取引が確定してしまう（オプション取引のように「権利放棄」はできない）点が、B-33のオプション取引との根本的な違いです。ヘッジの確実性は高い反面、有利な方向への価格変動のメリットを放棄することになる、というトレードオフを理解しておきましょう。

# まとめ：財務・会計の学び方

財務・会計は、他の科目以上に「計算を自分の手で再現できるか」が得点に直結する科目です。以下の順で学習を進めることをお勧めします。

1. **簿記の基礎（B-1〜B-9）を最優先で固める**：仕訳・貸借対照表・損益計算書の構造が理解できていないと、それ以降の経営分析・投資評価はすべて土台のない暗記になってしまいます。特に「資産・負債・純資産・収益・費用」の5要素と借方・貸方の対応関係、税効果会計の一時差異の向き（将来減算→資産、将来加算→負債）は繰り返し確認してください。
2. この教科書で全体像・計算式の意味を理解したら、`problem_sets/1st_stage/exercises/B_finance_accounting_exercises.md` の演習を解いて、実際の出題形式・計算過程に慣れてください。
3. `problem_sets/1st_stage/B_finance_accounting.md` の頻出ランク表を見て、Aランク論点（経営分析、CVP分析、資本コスト・WACC、投資評価（NPV・IRR）、ポートフォリオ理論・CAPM、企業価値評価、オプション取引など）を優先的に、繰り返し計算練習してください。
4. 過去問本体（`past_exams/1st_stage/1ji<年度>/b1ji<年度>.pdf`）で演習量を増やし、特に計算問題は「解答を見て理解した気になる」のではなく、必ず自分の手で最後まで計算し切る習慣をつけてください。

財務・会計は2次試験の事例IV（財務・会計）にそのまま直結する科目です。ここで学ぶ経営分析・CVP分析・NPV法などの計算の考え方は、1次試験の暗記としてだけでなく、2次試験の記述・計算問題を解くための土台にもなります。単に公式を暗記するのではなく、「なぜその計算式になるのか」「その数字は何を意味しているのか」を具体的な数値例とともに理解することが、遠回りに見えて最も確実な合格への道です。
