# SMEC標準図解スライド・デザインガイド

## 目的

教科書本文をそのまま貼り付けるのではなく、概念間の関係を図で理解できるスライドへ変換するための共通仕様です。

テンプレート本体は [`SMEC_visual_diagram_template.pptx`](SMEC_visual_diagram_template.pptx) です。すべてPowerPoint上で編集できる図形で構成しています。

## 参照した公開デザイン

- [WILLC公式PowerPointテンプレート](https://github.com/ShunAraki0622/willc-pptx-template)：PowerPointマスター、デザインガイド、Python実装を一体化する考え方を参照。コードはMIT Licenseですが、企業ロゴ・商標・固有意匠は使用していません。
- [IBM Carbon Design System](https://carbondesignsystem.com/)：グリッド、色の役割、タイポグラフィ、アクセシビリティの考え方を参照。
- 公開されている戦略コンサルティング資料に共通する「1スライド1メッセージ」「結論を示すアクションタイトル」「出典を固定位置に表示」という情報設計を参照。

既存企業のテンプレートを複製したものではなく、上記の公開原則をSMEC教材向けに再設計した独自テンプレートです。

## 選択ルール

1. スライドで伝える結論を一文にする。
2. 結論を支える関係が「構成・比較・順序・因果・循環・階層・時系列・分類・関係・数式・数値・経済曲線」のどれかを判断する。
3. 対応するパターンを1つ選ぶ。
4. 図だけで意味が伝わるよう、ラベル・軸・矢印・凡例を追加する。
5. 長い補足説明は教科書本文へ残し、スライドには結論と根拠だけを載せる。

## 禁止事項

- 教科書本文を段落のまま貼り付ける。
- 1枚に複数の主張を詰め込む。
- 同じ意味に異なる色を使う。
- 軸ラベル、曲線名、凡例のないグラフを置く。
- 読めない大きさまで文字を縮小する。
- 装飾目的だけのアイコン、影、グラデーションを加える。
