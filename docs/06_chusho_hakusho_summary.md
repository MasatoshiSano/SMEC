# 中小企業白書2026年版 要点まとめ（「中小企業経営・中小企業政策」科目対策）

出典：`references/whitepaper/R08_chusho_hakusho_gaiyo.pdf`、`R08_chusho_seisaku_chusho.pdf`（中小企業庁、2026年4月公表）。
数値の一部はPDFのフォント埋め込み方式の都合で本文抽出時に欠落している箇所がある。正確な数値が必要な場合は原本PDFを直接参照すること。

## 1. 白書全体のメインメッセージ（第1部・第2部の要旨）

- 日本経済の成長には中小企業の**持続的な賃上げ**が不可欠だが、労働供給制約社会の到来により人手不足がさらに深刻化するおそれがある。
- 供給力を維持・向上させるには、リスクを恐れず成長や変化に挑戦する経営へ転換し、「**稼ぐ力**」を高め「**強い中小企業**」へ成長することが重要。
- 「稼ぐ力」向上の両輪：
  1. **付加価値額の増加**：価格転嫁の推進、成長投資、事業承継・M&A等による事業再編
  2. **労働投入量の最適化**：AI活用・デジタル化の促進
- 実際にこれらに取り組む企業は、取り組んでいない企業と比較して付加価値額増加・労働投入量最適化を実現していることが白書内で確認されている（頻出の論点）。

### 第1部（令和7年度の動向）のポイント

- 春季労使交渉で約30年ぶりの賃上げ水準が継続、最低賃金の引き上げも進行。ただし大企業と比較して中小企業の賃上げ余力は厳しく、賃上げ原資の確保が課題。
- 2010年代以降、多くの業種で人手不足感が継続的に強まっている。労働供給制約社会の到来により中小企業の雇用者数減少が見込まれ、人手不足はさらに深刻化するおそれ。

### 第2部（「稼ぐ力」の強化）のポイント

- 現状維持は最大のリスク。短期的な損益より長期的視点での事業構造・組織構造の再構築（＝「戦略」を持った経営）への転換が重要。
- 「稼ぐ力」＝付加価値を生み出す力。労働投入量減少が見込まれる中、**労働生産性**（＝付加価値額 ÷ 労働投入量）の向上が不可欠。
- 中小企業の労働生産性の傾向：一人当たり労働時間は減少しつつも付加価値額が増加しており、時間当たり労働生産性は上昇傾向。大企業と遜色ない労働生産性を誇る中小企業も存在。

## 2. 令和7年度に講じられた主な中小企業施策（予算事業）

出題範囲「中小企業政策」の②中小企業支援事業の実施体制と政策に対応。主要な施策名は覚えておくこと（金額は年度により変動するため名称・目的を優先して記憶）。

### (1) 成長・生産性向上・省力化投資支援

- **中小企業生産性革命推進事業**：以下の複数の補助金の総称
  - 中小企業成長加速化補助金
  - ものづくり・商業・サービス生産性向上促進補助金（通称「ものづくり補助金」）
  - IT導入補助金
  - 小規模事業者持続化補助金
  - 事業承継・M&A補助金
- **中小企業新事業進出促進事業（新事業進出補助金）**：新事業進出・事業転換を重点支援
- **中小企業省力化投資補助事業（省力化補助金）**：オーダーメイド型・カタログ型の両方に対応
- **中堅・中小企業の賃上げに向けた省力化等の大規模成長投資補助金**：工場等拠点新設等の大規模設備投資を促進
- **100億企業育成ファンド出資事業**：中小機構出資によるファンド組成、リスクマネー供給とハンズオン支援
- **成長型中小企業等研究開発支援事業（Go-Tech事業）**：大学・公設試等と連携した研究開発支援
- **新規輸出1万者支援プログラム**：輸出実現支援（海外展開支援と関連）

### (2) 物価高・人手不足等への対応

- **価格転嫁対策**：中小企業取引対策事業、「価格交渉促進月間」（9月・3月）、下請代金支払遅延等防止法・下請中小企業振興法の改正、中小受託取引適正化法（取適法）・振興法の執行強化、「パートナーシップ構築宣言」の拡大
- **資金繰り支援**：日本政策金融公庫からの融資に対する利子補給、信用保証制度、資本性劣後ローン
- **省力化支援**：省力化補助金（上記再掲）
- **経営改善・早期再生・再チャレンジ支援**：中小企業活性化協議会による事業再生支援、事業承継・引継ぎ支援センター

### (3) 小規模事業者支援・災害復旧支援

- 商工会・商工会議所を通じた小規模事業者への巡回指導・窓口相談支援
- 小規模事業者経営改善資金融資事業（いわゆる「マル経融資」、無担保・無保証人・低利）
- 商店街等活性化支援事業
- なりわい再建支援事業・中小企業等グループ補助金（震災等の被災地域向け）

### (4) 事業承継・再編等を通じた変革の推進

- 中小企業活性化・事業承継総合支援事業
- 後継者支援ネットワーク事業
- 事業承継・M&A補助金

### (5) 地域課題解決・中堅企業支援

- 中小企業・小規模事業者ワンストップ総合支援事業（「よろず支援拠点」を各都道府県に整備）
- 中堅・中核企業の経営力強化支援事業、「地域の人事部」支援事業
- ローカル・ゼブラ企業（社会課題解決型企業）の創出・育成支援
- 「100億企業」創出加速に向けた調査・分析（売上高100億円超を目指す企業の経営者ネットワーク構築）

### (6) 令和8年度税制改正事項（中小企業関連）

| 税制措置 | 内容 |
|---|---|
| 中小企業経営強化税制 | 適用期限2年延長、「100億企業」を目指す中小企業向けに対象設備へ建物を追加 |
| 中小企業投資促進税制 | 設備投資への税額控除・特別償却を2年延長 |
| 固定資産税の特例措置 | 賃上げ表明企業向けの設備投資に伴う固定資産税特例を2年延長、賃上げ率に応じ軽減率を引上げ |
| 法人税軽減税率 | 中小企業者等の年800万円以下所得への軽減税率を2年延長 |
| 中小企業防災・減災投資促進税制 | 事業継続力強化計画に基づく設備投資の特別償却を2年延長 |
| 法人版・個人版事業承継税制 | 特例措置に限り、後継者の役員就任期間（3年）・事業従事期間（3年）要件を事実上撤廃 |

## 3. 学習のポイント

- 「中小企業経営・中小企業政策」科目は**当年度の白書内容がそのまま出題される実務色の強い科目**。過去問の論点（中小企業基本法上の定義、中小企業性業種、経営指標等）に加え、**最新の白書の第1部・第2部の問題意識と、当年度の主要施策名**を必ず押さえること。
- 補助金・支援策は名称が毎年改定されることがあるため、直前期には最新の中小企業庁公式情報で名称・要件を再確認すること（`docs/05_sources.md` に索引ページのURLを記載）。
- 数値の細部（予算額等）は出題頻度が低く、白書全文または政府予算資料でしか正確な値が追えないため、本サマリーでは名称・制度趣旨を優先している。
