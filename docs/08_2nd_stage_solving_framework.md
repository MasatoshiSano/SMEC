# 第2次試験 解答プロセスと事例別フレームワーク

このドキュメントは、公式の「出題の趣旨」（`past_exams/2nd_stage/shushi/`）や試験案内の記載事項を踏まえつつ、2次試験に共通する一般的な解答アプローチを整理したものである。公式に採点基準・模範解答は公表されていないため、ここでの内容は受験対策として広く共有されている考え方の整理であり、公式見解ではない。

## 1. 全事例共通の解答プロセス（一般的に推奨される進め方）

1. **設問文を先に読む**：与件文を読む前に設問（要求内容・制約条件・文字数）を把握し、何を探しながら読むかを決める。
2. **与件文を読みマーキング**：強み・弱み、機会・脅威、時制（過去・現在・将来）、経営者の想いなどにマーカーで印を付ける。
3. **設問と与件文の対応付け**：各設問がどの段落・情報に対応するかを整理する（レイヤー分け）。
4. **解答の骨子作成**：「誰が」「何を」「どうする」「その結果どうなる（効果）」という構造で骨子を作る。
5. **文字数調整**：因果関係を明確にした一文を心がけ、規定文字数に収める。
6. **一貫性チェック**：事例全体を通じて経営戦略の方向性に矛盾がないか確認する（例：事例I〜IVすべてで「差別化戦略」なのに一部で「コスト戦略」の解答をしていないか等）。

与件文に書かれていない情報を独自に推測して解答すると減点対象になりやすい、というのが受験対策コミュニティでの共通認識である。**与件文に根拠のない一般論は書かない**ことが重要とされる。

## 2. 事例I（組織・人事）の頻出フレームワーク

- **「幸の日も毎日（さちのひもまいにち）」フレームワーク**（人事施策の切り口、受験対策コミュニティで広く使われる語呂合わせ）：
  - 採用、配置、育成、評価、報酬、モチベーション、退職
- 組織構造の切り口：組織形態（職能別・事業部制）、権限委譲、階層のフラット化
- 経営者の想い・戦略と組織構造・人事施策の整合性を問う設問が多い（「戦略は組織に従う」「組織は戦略に従う」の両方の視点）
- 頻出テーマ：事業承継、多角化に伴う組織再編、非正規社員の活用、社員のモチベーション向上

## 3. 事例II(マーケティング・流通)の頻出フレームワーク

- **ダナドコ**（受験対策コミュニティの語呂合わせ）：誰に（ダ=誰）、何を（ナ=何）、どのように（ド=どのように）、効果（コ=効果）
- **STP＋4P** の型で解答を構成する（`07_key_formulas_and_frameworks.md` 参照）
- 中小企業ならではの強み（地域資源、職人技術、顧客との関係性）を生かした差別化戦略が問われやすい
- 頻出テーマ：関係性マーケティング（既存顧客との関係深耕）、地域資源の活用、オンライン活用・ITを絡めた販路開拓

## 4. 事例III（生産・技術）の頻出フレームワーク

- 生産管理の基本切り口：QCD（Quality品質・Cost コスト・Delivery 納期）
- 生産形態の把握：受注生産か見込生産か、個別生産か連続生産か（`07_key_formulas_and_frameworks.md` の生産管理を参照）
- 問題点抽出の切り口：生産計画、生産統制、作業管理、設備管理、資材管理、品質管理のどこに課題があるかを整理
- 頻出テーマ：多品種少量生産への対応、生産計画の精度向上、情報の一元管理（生産管理システムの導入）、多能工化

## 5. 事例IV（財務・会計）の頻出フレームワーク

- 経営分析：`07_key_formulas_and_frameworks.md` の収益性・効率性・安全性の指標から、与件文・財務諸表の特徴を示す指標を2〜3個選んで論述する設問が定番。
- CVP分析（損益分岐点分析）：固定費・変動費の分解、損益分岐点売上高の計算
- 意思決定会計：NPV法・IRR法による設備投資の可否判断、差額原価収益分析
- 頻出論点：セグメント別収益性分析、資金繰り（キャッシュフロー計算）、企業価値評価
- 計算問題は部分点狙いで、計算過程を残す解答様式が推奨される（電卓使用可、`00_exam_system_overview.md` の持込み規定参照）

## 6. 学習の進め方（外部情報源からの要約）

1. 1次試験の「企業経営理論」「運営管理」「財務・会計」の知識を土台として先に固める。
2. 過去問（`past_exams/2nd_stage/questions/`）を80分の制限時間で解く練習を繰り返す。
3. 解答後は「出題の趣旨」（`past_exams/2nd_stage/shushi/`）で論点を外していないか確認し、市販の再現答案分析本（`04_study_materials_guide.md`）で採点基準の傾向をつかむ。
4. 事例IVは計算力がものを言うため、独立した計算問題集で毎日一定時間の演習を継続することが推奨されている。

## 7. 注意：口述試験廃止（令和8年度〜）との関係

`00_exam_system_overview.md` に記載の通り、令和8年度より口述試験は廃止され、筆記試験の結果のみで合否が決まる。過去の合格体験記にある口述試験対策（想定問答集、事例内容の再確認等）は令和7年度以前の情報であり、令和8年度以降は不要となる。
