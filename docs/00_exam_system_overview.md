# 中小企業診断士 試験制度の全体像

出典：JF-CMCA（一般社団法人日本中小企業診断士協会連合会）公式試験案内（`docs/official_guides/`）、中小企業庁公式発表。詳細な出典URLは `05_sources.md` を参照。

## 1. 資格の根拠法・実施機関

- 中小企業診断士は「中小企業支援法」第11条に基づき、経済産業大臣が登録する国家資格。
- 試験は同法第12条に基づき実施され、実施機関は経済産業大臣指定試験機関である**一般社団法人 日本中小企業診断士協会連合会（JF-CMCA）**。
- 2024年10月、旧名称「一般社団法人中小企業診断協会」から現名称に改称（ドメインも j-smeca.jp → jf-cmca.jp に変更）。

## 2. 試験の全体構成

```
第1次試験（マークシート・7科目）
   └─ 合格（有効期間2年）または科目合格（翌年度・翌々年度に免除申請可、3年以内に7科目そろえば1次合格）
        └─ 第2次試験
             ├─ 筆記試験（事例I〜IV、記述式）
             └─ 口述試験 ※令和8年度より廃止（後述）
                  └─ 合格
                       └─ 実務従事 or 実務補習（合計15日以上）
                            └─ 中小企業診断士として登録（有効期間5年、更新要件あり）
```

養成課程ルート：第1次試験合格者は、合格年度と翌年度の2年間に限り、中小企業基盤整備機構または登録養成機関が実施する「中小企業診断士養成課程」を受講することで、第2次試験・実務補習を経ずに登録可能。

## 3. 第1次試験の概要

| 項目 | 内容 |
|---|---|
| 目的 | 中小企業診断士となるのに必要な学識を有するかを判定 |
| 方式 | マークシート方式・多肢選択式の筆記試験 |
| 受験資格 | 年齢・学歴等の制限なし |
| 実施地区 | 札幌・仙台・東京・名古屋・金沢・大阪・広島・松山（四国）・福岡・那覇の10地区 |
| 実施時期 | 例年8月上旬の土日（令和8年度：8月1日・2日） |
| 申込方法 | 令和7年度からWeb申込システムのみ（払込取扱票による旧方式は廃止） |
| 受験手数料 | 17,200円（令和8年度、非課税）＋オンライン決済事務手数料590円 |
| 合格発表 | 例年9月上旬（令和8年度：9月1日、Webのみで発表） |

### 試験科目・配点・試験時間（令和8年度）

| 時限 | 時間 | 分数 | 配点 | 科目 |
|---|---|---|---|---|
| 1 | 9:50〜10:50 | 60分 | 100点 | A 経済学・経済政策 |
| 2 | 11:30〜12:30 | 60分 | 100点 | B 財務・会計 |
| 3 | 13:30〜15:00 | 90分 | 100点 | C 企業経営理論 |
| 4 | 15:40〜17:10 | 90分 | 100点 | D 運営管理（オペレーション・マネジメント） |
| 5 | 9:50〜10:50 | 60分 | 100点 | E 経営法務 |
| 6 | 11:30〜12:30 | 60分 | 100点 | F 経営情報システム |
| 7 | 13:30〜15:00 | 90分 | 100点 | G 中小企業経営・中小企業政策 |

（1日目：A〜D、2日目：E〜G。法令等に関する問題は原則として試験実施年5月1日時点で施行されている法令に基づき出題。）

### 合格基準

- **第1次試験合格基準**：総点数の60％以上、かつ1科目でも満点の40％未満がないこと（試験委員会が相当と認めた比率で補正される場合あり）。
- **科目合格基準**：満点の60％を基準とする。
- 1科目でも欠席がある場合は第1次試験合格基準は適用されず、受験科目それぞれが科目合格基準で判定される。

### 科目免除制度

1. **科目合格による免除**：前年度・前々年度に科目合格した科目は、申請により翌年度・翌々年度まで免除可（3年以内に全7科目そろえば1次合格）。ただし、いったん第1次試験に合格すると、それ以前の科目合格による免除申請資格は消滅する。
2. **他資格保有による免除**：以下の資格等保有者は該当科目が免除される（要証明書類アップロード）。
   - 経済学・経済政策：大学等の経済学教授等（通算3年以上）、経済学博士、公認会計士試験で経済学合格者など
   - 財務・会計：不動産鑑定士、公認会計士（試験合格者含む）
   - 経営法務：税理士（試験合格者・免除者含む）、弁護士・司法試験合格者
   - 経営情報システム：技術士（情報工学部門）、情報処理技術者試験の一部区分合格者（ITストラテジスト、システムアーキテクト、応用情報技術者など）

## 4. 第2次試験の概要

| 項目 | 内容 |
|---|---|
| 目的 | 中小企業診断士となるのに必要な応用能力を有するかを判定 |
| 方式 | 短答式・論文式による筆記試験（＋従来は口述試験） |
| 受験資格 | 当年度または前年度の第1次試験合格者。平成12年度以前の第1次試験合格者は1回に限り第1次試験免除で受験可 |
| 実施地区 | 札幌・仙台・東京・名古屋・大阪・広島・福岡の7地区（金沢・松山・那覇での実施なし） |
| 実施時期 | 例年10月（令和8年度：10月25日） |
| 受験手数料 | 15,100円（令和8年度、非課税）＋オンライン決済事務手数料525円 |
| 合格発表 | 例年1月（令和8年度：令和9年1月13日） |

### 筆記試験の科目構成

| 時限 | 時間 | 分数 | 配点 | 事例 | テーマ |
|---|---|---|---|---|---|
| A | 9:40〜11:00 | 80分 | 100点 | 事例I | 組織（人事を含む）を中心とした経営の戦略及び管理 |
| B | 11:40〜13:00 | 80分 | 100点 | 事例II | マーケティング・流通を中心とした経営の戦略及び管理 |
| C | 14:00〜15:20 | 80分 | 100点 | 事例III | 生産・技術を中心とした経営の戦略及び管理 |
| D | 16:00〜17:20 | 80分 | 100点 | 事例IV | 財務・会計を中心とした経営の戦略及び管理 |

出題テーマは「経営革新・改善」「新規事業開発（既存事業の再生を含む）」等から出題される。

### 合格基準

筆記試験の総点数60％以上、かつ1科目でも満点の40％未満がないこと。

### 出題の趣旨

模範解答は公表されないが、合格発表日午前中に事例ごとの「出題の趣旨」がWeb公表される（`past_exams/2nd_stage/shushi/` に令和2〜7年度分を保存）。

## 5. 【重要】令和8年度からの制度変更

中小企業診断士の登録等及び試験に関する規則が令和7年6月25日付で改正され、以下が変更された。

1. **口述試験の廃止**：令和8年度（本リポジトリ作成時点の最新年度）より、第2次試験の口述試験が廃止。第2次試験は筆記試験のみで合否が決定する。
   - 廃止の理由（公式発表）：試験の安定的実施、受験者の負担軽減、試験実施団体の経費削減・プロセス効率化。
2. **受験手数料の改定**（総額は32,300円で変更なし）：
   - 第1次試験：14,500円 → **17,200円**
   - 第2次試験：17,800円 → **15,100円**
3. **申込方法**：令和7年度からインターネット出願（Web申込システム）に完全移行。従来の払込取扱票による申込は廃止。

※令和7年度以前の情報を扱う教材・Webサイトでは「口述試験あり」を前提とした記述が残っているため、学習時は年度に注意すること。

## 6. 登録・更新要件

- 第2次試験合格後、登録申請日前3年以内に「実務従事」または「実務補習」を合計15日以上行うことで登録可能。
- 登録の有効期間は5年間。更新には以下の両方が必要：
  1. 知識の補充要件：5年間で理論政策更新研修等を5回以上受講
  2. 実務の従事要件：5年間で30日以上（1日1点換算）の診断助言等の実務
- 登録拒否事由：未成年者、破産者（復権前）、拘禁刑以上の刑に処せられ3年未経過の者、各種資格の登録取消処分を受けて3年未経過の者 等（詳細は試験案内15章参照）。

## 7. 学習スケジュールの目安（外部情報源、参考値）

複数の予備校・資格情報サイトの記載を集約した一般的な目安（公式発表ではない点に注意）：

- 1次試験対策：800〜1,000時間程度
- 2次試験対策：350〜500時間程度
- 合計：1,000〜1,200時間程度が独学合格の目安とされることが多い
