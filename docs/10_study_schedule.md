# 学習スケジュール（逆算プラン）

`problem_sets/` の頻出ランク・演習フォーマットに対応させた学習計画。**次回受験を想定した設計図であり、確定した試験日程ではない**（令和9年度の正式な試験案内はまだ公表されていない。例年のパターン＝1次試験8月第1土日、2次試験10月最終日曜、から想定）。正式発表され次第、`docs/00_exam_system_overview.md` と合わせて日付を更新すること。

## 前提

- 起点：2026年9月（本リポジトリ整備時点）
- 1次試験（想定）：2027年8月上旬
- 2次試験（想定）：2027年10月下旬（令和8年度から口述試験廃止のため、筆記試験のみで合否確定）
- 総学習時間の目安（`docs/04_study_materials_guide.md`）：1次800〜1,000時間、2次350〜500時間

## 科目別の優先順位（フェーズA・Bで参照）

`04_study_materials_guide.md`の一般的な学習順に、`problem_sets/`のAランク論点の多さ（＝出題される論点の広さ）を加味して優先順位を設定する。

| 優先度 | 科目 | 理由 |
|---|---|---|
| 最優先 | B 財務・会計 | 2次試験の事例IVに直結。計算力は積み上げが必要なため早期着手が有利。Aランク論点25/34と幅広い。 |
| 最優先 | C 企業経営理論 | 2次試験の事例I・IIに直結。出題数が多く（1年33〜40問）、Aランク論点39/42とほぼ全域が頻出。 |
| 高 | D 運営管理 | 2次試験の事例II・IIIに直結。生産管理・店舗販売管理ともAランクが大半（`D_operations_management.md`参照）。 |
| 中 | A 経済学・経済政策 | 積み上げ型科目のため計画的に。マクロ・ミクロの基礎理論から。 |
| 中 | E 経営法務 | 知的財産権・会社法・民法が最頻出（`E_business_law.md`参照）。暗記中心だが法改正情報は最新化が必要。 |
| 中 | F 経営情報システム | 技術トレンドの影響を受けやすく、直近年度の頻出用語（AI、クラウド、セキュリティ）を重視。 |
| 直前期に重点 | G 中小企業経営・中小企業政策 | 当年度の中小企業白書がそのまま出題範囲になるため、試験年度の最新白書公表後（毎年4月頃）に本格着手するのが効率的。基本法の定義（`07_key_formulas_and_frameworks.md`）だけは早期に暗記しておく。 |

## 週次学習時間の目安（フェーズA・B、平日+週末型）

- 平日：1〜1.5時間 × 5日 ＝ 5〜7.5時間
- 週末：4〜6時間 × 2日 ＝ 8〜12時間
- 週合計：13〜19.5時間

上記×34週（フェーズA＋B）で概算442〜663時間。フェーズC・Dで残り時間を積み増し、1次試験までに800〜1,000時間規模に到達させる想定。

## 注意事項

- 令和9年度の正式な試験日程・科目免除ルール等は、公表され次第 `docs/00_exam_system_overview.md` を更新し、本スケジュールの日付も合わせて修正すること。
- 科目合格制度（`docs/00_exam_system_overview.md`参照）を使う場合は、上記スケジュールを複数年計画に組み替える必要がある（例：1年目は3〜4科目に絞って確実に合格を狙う等）。
