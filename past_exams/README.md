# 過去問ディレクトリ

出典：JF-CMCA（一般社団法人日本中小企業診断士協会連合会）公式サイト。詳細は `../docs/05_sources.md` 参照。

## 構成

- `1st_stage/1ji<年>/` : 第1次試験 問題本体（平成19年度〜令和8年度、科目A〜G）。`1ji(sai)2023` は令和5年度の再試験分。
- `1st_stage_answers/r05〜r08/` : 第1次試験 正解・配点（令和5〜8年度分を収録。令和4年度以前が必要な場合は `attach/test/<年度>/1ji_seikai/` パターンで追加取得すること）。
- `2nd_stage/questions/2ji<年>/` : 第2次試験 問題本体（平成19年度〜令和7年度、事例A〜D）。
- `2nd_stage/shushi/<年度>/` : 第2次試験「出題の趣旨」（平成16年度〜令和7年度、全年度網羅）。模範解答は公式には非公表。平成17年度分はPDFが暗号化＋特殊フォント埋め込みのためOCRテキスト（`*_ocr.txt`、認識誤りを含む参考用）を併記。

## ファイル名の科目対応（第1次試験）

A=経済学・経済政策、B=財務・会計、C=企業経営理論、D=運営管理、E=経営法務、F=経営情報システム、G=中小企業経営・中小企業政策

## ファイル名の事例対応（第2次試験）

A=事例I（組織・人事）、B=事例II（マーケティング・流通）、C=事例III（生産・技術）、D=事例IV（財務・会計）

## 利用上の注意

個人の学習目的での利用を前提とする。再配布・商用利用はしないこと。
